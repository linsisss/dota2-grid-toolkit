# Design System: GridStudio Focus editor

## Overview

**Creative North Star: "Focus — a clear workspace around the game board"**

Focus is selected and applied to the working editor at index.html, following the user's choice on 2026-09-26. The active system is extracted from styles/focus.css, the later editor-actions.css and editor-controls.css interaction layers, the inherited editor styles, the React editor controls, and renderer overrides. Its dark violet surfaces, lavender selection states, vertical floating tools, and separate property panel keep the game board central while retaining the working editor's controls.

The five designs in design.html remain unchanged as reference concepts. Their existing Ancient, Canvas, Focus, Play, and Atlas token namespaces describe that gallery; editor-* tokens describe the selected working editor and take precedence there. The landing remains unselected. The original angular logo and its lettering are preserved; the mark is recolored with the Focus accent.

**Key Characteristics:**

- Selected Focus editor with a mode library and an initially closed properties/layers panel.
- Original angular GridStudio logo, recolored without changing its geometry.
- SF Pro Display interface, Radiance game content, and retained editing controls.
- Five reference concepts preserved; landing selection remains open.

## Colors

Frontmatter contains two explicitly separated scopes. The editor-* colors follow the live Focus override, including its actual panel, field, and workspace fills. The earlier candidate prefixes retain the unchanged values in src/design/design.css. Sidecar tonal strips are generated panel previews, not additional implemented palette tokens.

### Primary

The selected editor uses soft lavender for the primary action, active tools, selection outlines, and the original mark. A brighter lavender provides primary hover feedback; the translucent accent supports selected rows and expanded panel controls. Dark accent-ink keeps filled active controls readable. The toolbar uses a filled accent for the current tool.

Gallery reference accents remain armory gold (Ancient), iris blue (Canvas), lavender (Focus), lime with an aubergine action (Play), and deep green (Atlas). None of the gallery landing treatments has been selected.

### Neutral

The live page uses editor-bg, the inspector and dialogs use editor-panel, and hovered secondary controls use editor-panel-raised. Fields use editor-field and the surrounding workspace uses editor-surround. The editor shell and floating dock have separate base fills, captured as editor-shell and editor-dock. The later interaction stylesheet gives the labelled dock a scoped fill (#312b3c), brighter idle labels (#e2daef), and hover surface (#494054); these component overrides do not replace the preserved palette primitives. Main, muted, and subtle text remain distinct. Lines separate sections without enclosing the entire workspace.

The added form-* tokens describe intentional control details: checkbox boundaries, range tracks/thumb rings, step-button hover, and the customizable select popup. Preview-* tokens are confined to the warm Dota presentation background and its close control; they do not replace the violet Focus workspace palette.

The real renderer uses the editor-board fill and matching lavender selections in scripts/app.mjs and src/DrawingDialog.jsx. These presentation values do not define document data or game geometry.

**The Scope Rule.** Apply editor-* tokens to the working editor. Gallery tokens remain reference values, and the editor choice does not select a landing.

## Typography

**Interface Font:** SF Pro Display, with Apple, Segoe UI, and sans-serif fallbacks.
**Game Font:** StudioRadiance, the CSS family name for Radiance, with sans-serif fallback.

### Hierarchy

The live editor has a 12px base. Header actions and mode labels use 13px; property fields use 14px; the inspector title uses 16px bold, subsection headings use 14px medium, and drawer titles use 21px. Hints use 12px with 1.55 leading. The frontmatter's editor-* typography roles are the live interface roles. The export guide deliberately uses 15px body text at 1.6 leading and 20px headings; the desktop dock-label toggle uses a compact 10px label. The supported custom select popup uses 13px/1.4 interface text.

The five display roles, gallery body/action/field roles, and canvas-heading role are preserved reference tokens. Their large landing headings and SVG coordinate sizes are not the working editor's UI scale. Gallery descriptions retain their 39ch maximum (Focus: 37ch). SF Pro uses the declared local or remote font sources; this record does not assert offline font availability.

**The Game Type Rule.** Keep Radiance and game geometry in the game plane; use the interface type roles for tools and properties.

**The Original Art Rule.** Preserve the supplied Unicode artwork, including Braille characters. Never replace Braille with ordinary dots. Catalogue previews and insertion use the same game-text measuring and rendering path.

## Layout

### Selected editor

The application occupies the viewport. A 66px header contains the original brand, project controls, and JSON actions. A 48px navigation row holds modes, grid selection and renaming, then Settings before the book-shaped help button. There is no status footer; the upstream repository attribution is available in help. The right inspector starts closed on both desktop and mobile. When opened, the desktop workspace has a flexible board plus a 280px inspector, with 16px padding and gap. The inspector grows to 310px at 1600px and above; at 1100px and below it contracts to 250px with 12px spacing.

A vertical floating tool dock sits to the left of the board, beginning with an add-hero-group control. Desktop tool buttons are 112px wide and 36px high, with 18px icons and 12px medium labels. A final dock control toggles labels, switching to 36px icon buttons and retaining that preference in localStorage under gridstudio.dock.compact. At 900px and below the dock already uses icons and hides the label toggle (34px default width, 36px when the saved compact preference applies); short viewports reduce tool height to 25px. The board's left margin is 154px on desktop, 76px at 900px and below, and 64px at 700px and below. Opening the left library moves the dock right by the library width, keeping it available beside the panel. History and preview controls sit at the workspace's upper right; recent symbols occupy the top strip. Symbol/category counts, grid and snap controls, and zoom remain available below the board. The right panel contains both editing fields and layers. It is not the simplified Focus gallery mockup.

The mode tabs toggle the left library, whose width is min(310px, 100vw minus 72px) and whose edge insets follow workspace padding. Selecting another mode switches its contents; selecting the same open mode closes it. Settings, equivalent to F, toggles the right properties/layers panel. At widths of 900px and below, that panel opens as a right overlay, capped at 310px and constrained to the viewport; opening either panel closes the other. At 700px and below, navigation becomes two rows (90px total); the header becomes 60px and workspace padding becomes 8px. The second navigation row places Settings before help. Counters and grid/snap controls wrap into lower rows. Narrow layout hides selected redundant labels and compact grid-file buttons while keeping the project workflow accessible.

For desktop widths above 700px and heights at or below 620px, the header becomes 54px, navigation 40px, and the dock becomes denser. Closing Settings collapses the desktop inspector column to zero and removes its gap; the hidden panel is inert and unavailable to pointer input.

### Gallery reference

The comparison gallery retains its 2040px outer limit and independently sized landings. Ancient frames the screenshot beside its gold title; Canvas tilts the evidence on a light plane; Focus extends it from the left; Play spans both columns with the title; Atlas divides the screenshot field from its information column.

Its editor references remain: Ancient 185px library / board / 232px inspector; Canvas 61px rail / board / 245px inspector; Focus board / 245px inspector; Play 60px rail / board / 225px inspector; Atlas 205px tree / board. Gallery breakpoints at 1180px, 840px, and 620px remain separate from the live editor breakpoints.

## Elevation & Depth

The live shell has no shadow. Tone separates the shell, field, inspector, and surrounding workspace. Elevation identifies floating controls and open overlays. Primary hover adds a small neutral shadow, distinct from overlay elevation.

### Shadow Vocabulary

- **Primary hover** (`0 5px 16px #0003`): subtle lift on the highlighted action.
- **Floating dock** (`0 8px 24px #0004`): separates the vertical tool palette from the board.
- **Mode library drawer** (`12px 12px 44px #0008`): lifts the left overlay.
- **Narrow properties drawer** (`-12px 12px 44px #0008`): lifts the right overlay.
- **Dialog backdrop** (`#0b0912b8`): dims the editor behind modal work.
- **Tooltip** (`0 5px 18px #0006`): raises the top-layer hint above its target.
- **Context menu** (`0 14px 46px #0008`): separates contextual actions from the canvas.
- **Custom select picker** (`0 12px 28px #0006`): lifts supported native-semantic picker surfaces.

Gallery screenshot shadows remain reference treatments: Canvas's cooler lift, Focus's dark separation, Play's violet mat, and Atlas's restrained green shadow. They are not promoted to live editor panel tokens.

## Shapes

The live editor uses 8px header actions, 6px property fields and tool buttons, 10px shell/inspector/dock corners, and a 12px mode library drawer. The game viewport uses 4px corners. These explicit component radii matter more than assuming the root radius applies everywhere.

The original mark's path is `m5 4 23 24M5 18v10h10M18 4h10v10` in its 32×32 viewBox. Its shape and GRIDSTUDIO lettering are preserved. The gallery's different mark remains confined to that unchanged reference artifact.

**The Original Mark Rule.** Preserve the original angular SVG path and lettering; only the mark color changes to the editor accent.

Gallery shape tokens also remain unchanged: compact Ancient/Atlas controls, rounded Canvas/Focus controls, larger Play surfaces and pill actions, and author pills.

## Components

### Buttons

Live primary buttons use accent fill with accent-ink text and the brighter accent on hover. Secondary buttons use raised panels and a darker violet hover fill; ghost controls change from muted to main text. Header actions are 36px high with 8px corners; common buttons have 6px corners and 0 13px padding. Inspector actions use 12px text.

Keyboard focus uses a 2px accent outline with 3px offset. Disabled controls retain the inherited 0.3 opacity and unavailable cursor. Existing hover/press motion is retained; selected toolbar tools use filled lavender, while selected layer rows use translucent lavender.

### Chips

Live count badges use the raised panel, muted text, compact padding, and small corners. Hero chips retain the real portrait and removal control in the inspector, using field backgrounds and line boundaries. The gallery author pills remain reference links and do not define editor controls.

### Cards / Containers

The right inspector opens on demand and contains scrollable properties and layers; it occupies a desktop column or overlays narrow screens. Mode-specific controls occupy the separate left library overlay. Both panels begin closed. Dialogs for hero selection, drawing, and ASCII use the same panel, field, text, and accent assignments as the main editor. The sidecar demonstrates source-derived live components; its examples do not represent new behavior.

### Inputs / Fields

Live fields use editor-field, text, line borders, and an accent caret. Hover lightens the border. Inspector fields use 14px text, at least 36px height, and 8px 10px padding. Selects and input units follow the same assignments. Search focus and hero choices use the accent boundary; the hero picker keeps actual selection state.

Numeric inputs retain their native min/max/step semantics but replace browser spinner chrome with two labelled arrow buttons in a 22px rail. Shift-click steps by ten increments; disabled/read-only controls cannot step. Checkboxes use 16px squares, 4px corners, and explicit checked/indeterminate marks. Ranges use a 4px track and lavender circular thumb. Search fields use a custom clear glyph; details summaries use a rotating chevron while preserving disclosure semantics.

Selects retain native keyboard behavior and a custom field chevron. Browsers supporting appearance: base-select also receive the styled top-layer picker: 8px corners, 5px container padding, 34px minimum options, and a maximum height of min(340px, 60dvh). Selected options use the dedicated translucent selection token and a lavender checkmark. Other browsers keep their native popup fallback.

Canvas width and height are edited directly in the caption and the empty-selection inspector; there is no separate size dialog. Caption number-field wrappers are 80px wide with at least 30px inputs, narrowing to 76px on phones. Blur or Enter validates and commits dimensions; Escape restores the relevant edit. Invalid dimensions produce an inline alert. The inspector also offers a reset to 1193 × 593.

When either canvas dimension exceeds that default, the editor draws a dashed lavender 1193 × 593 guide and tints the extra area. The guide is presentation-only and is absent in preview; it is not inserted into the document or exported artwork.

### Navigation

Mode tabs retain their accessible tab semantics, lavender selected text, and a visible 1px accent underline while toggling the left library. The single Settings control precedes help, controls the right inspector at every viewport, and shares its action with F. Its aria-expanded state and translucent accent reflect whether the panel is open. Help uses a book icon and includes shortcuts plus upstream attribution. Escape and dismiss controls close panels and return focus to the relevant trigger. The gallery's comparison tabs are not part of the selected product navigation.

### Context menu and tooltips

The canvas context menu is 284px wide, constrained within an 8px viewport margin, and scrolls when its height exceeds the available viewport. It groups tools, history, creation, selection, clipboard, two reflection icon controls, fit, and delete actions. Available actions use main text; checked tools use the existing accent treatment; unavailable actions reduce opacity to 0.4. The menu has 11px corners, 34px minimum row height, and an explicit destructive-action tint.

The horizontal and vertical reflection buttons are 40 × 34px with 21px mirrored-triangle icons. They reflect selected item positions while keeping glyphs upright; they do not substitute characters or mirror the rendered letters.

Right-clicking an unselected object selects it before showing the menu. The menu and keyboard shortcuts share the same internal clipboard; context paste anchors the copied selection at the invocation point. Arrow keys and Home/End move through enabled entries; Escape or Tab dismisses and restores canvas focus. Outside pointer input, scrolling outside the menu, or resizing also dismisses it.

Custom tooltips use a manual popover with role=tooltip and temporary aria-describedby linkage. They appear after 260ms of pointer hover or immediately on keyboard focus, above the target with a 10px gap when space allows, otherwise below it. Their horizontal position stays within 8px of the viewport edges. A trailing shortcut becomes a separate keycap. Pointer press, key input, blur, scrolling, and resize dismiss the hint. Tooltip corners are 7px, with 9px 12px padding and 12px/1.4 interface text.

### Original artwork catalogue

The ASCII library contains 43 supplied Unicode artworks from arts.txt, recorded in data/ascii-arts.json. Search matches names and categories, a category selector narrows results, and two-column preview cards initially show 12 items with incremental loading. Card previews are 130px tall. The library preserves the original visible characters, including Braille; layout only removes surrounding blank space and common indentation.

Selecting a card opens a larger preview capped at 900 × 740px, with the art's dimensions and an oversize notice when needed. Add to canvas creates one artwork layer containing editable text rows and selects the result. The dialog returns focus to its trigger on close. On phones it uses the available viewport and wraps footer controls. This local supplied-art library is separate from the still-unbuilt public grid catalogue.

## 📖 О проекте

Набор из **трёх браузерных инструментов**, которые в связке позволяют собрать готовый `hero_grid_config.json` для Dota 2:

- из картинки — через автоматический конвертер `Line-Art → символы`;
- из готовой чужой сетки — через импорт и правку;
- с нуля — вручную рисуя символами.

Все инструменты — **один HTML-файл = один инструмент**. Открываются двойным кликом в браузере, работают **полностью офлайн**, никуда не отправляют данные и не требуют установки.

Холст у всех — **1193 × 593 px** (safe area клиента Dota 2). Всё, что нарисовано внутри, экспортируется в JSON с координатами 1:1.

## 🖼 Line-Art Converter v7.1

**`tools/lineart-converter.html`** — автоматически превращает любую картинку в плотный набор символов.

### Как это работает

1. Картинка уменьшается до ~500 px по ширине.
2. **Canny edge detection** — поиск контуров (Sobel → NMS → гистерезис).
3. **Zhang-Suen thinning** — утоньшение линий до 1 px.
4. **Пространственный сэмплинг** — прореживание по сетке `gridStep`.
5. **Автоориентация** — каждому контуру подбирается символ по углу: `-`, `|`, `/`, `\`.
6. **Shading** — тёмные области заливаются символами из отдельного набора.

### Ключевые параметры

| Параметр | Смысл |
|---|---|
| `Blur σ` | Сглаживание (больше → меньше шума, но теряются детали) |
| `Threshold` | Порог силы контура |
| `Скелетизация` | Утоньшение линий (включай почти всегда) |
| `Заполнение холста %` | Какую долю 1193×593 займёт рисунок |
| `Шаг сетки (px)` | Толщина/плотность: 2 = очень плотно, 4 = стандарт, 8+ = пунктир |
| `Плотность %` | Множитель количества символов |
| `Заливка теней` | Символы, плотность и порог тени |

### Библиотека символов

18 категорий: градиент, точки, стрелки, геометрия, звёзды, карты, типографские, линии (4 и 8 направлений), армянский, иврит, арабский, тайский, хирагана, катакана, хангыль, латиница, кириллица.

### Пресеты

30 готовых пресетов лежат в `presets/presets.json`. Импорт: `📥 Импорт файла` → выбрать файл. Дальше — клик по пресету для загрузки.

Свои пресеты сохраняются в localStorage. `📤 Экспорт всех` выгрузит их обратно в JSON.

### Экспорт

- `💾 СКАЧАТЬ JSON` — сохраняет `lineart_free.json` в формате Dota.
- `📋 Копировать ASCII` — ASCII-карта в буфер обмена.

## ✏️ Pixel ASCII Editor v7.4

**`tools/pixel-ascii-editor.html`** — ручной редактор символов на холсте.

### Возможности

- **14 инструментов**: карандаш, линия, горизонталь, вертикаль, прямоугольник (контур/заливка), эллипс, ромб, треугольник, звезда, спираль, волна, рамка, заливка.
- **Конструктор рамок** — 9 слотов + 15 готовых пресетов (`simple`, `double`, `round`, `dotted`, `heavy`, `deco`, `star`, `heart`, `music`, `snow`, `cross`, `spade`, `dotdec`, `wavy`, `geometric`).
- **Библиотека символов** — 18 категорий.
- **Мульти-режим** — рисование случайным символом из набора.
- **Слои** — Фон / Основной / Декор.
- **Симметрия H/V** — мгновенное зеркалирование при рисовании.
- **Safe Area** — красная рамка границ Dota.
- **Dota Preview** — полотно 1:1 как в игре.

### Операции с выделением

- Повороты `90° / 180° / 270°`, отражения `H / V`.
- Копировать / Вставить / Дублировать / Удалить.
- Масштаб: `×1.25`, `×0.8`, `⛶ Заполнить холст`, `↺ Сброс`.
- Замена символа во всех выделенных.

### Импорт / Экспорт Dota-JSON

- Перетащи `hero_grid_config.json` — категории превратятся в символы.
- `💾 СКАЧАТЬ JSON` — сохраняет `pixel_art_hero_grid.json`.

### Горячие клавиши

| Клавиша | Действие |
|---|---|
| `P` | Dota Preview |
| `S` | Выделение области |
| `G` | Сетка |
| `M` / `N` | Симметрия H / V |
| `F` | Рамка |
| `1`–`9` | Выбор символа из активной категории |
| `Ctrl+Z` | Отмена |
| `Ctrl+C/V/D/A` | Копир. / Вставка / Дубль / Выделить всё |
| `Q` / `E` | Поворот −90° / +90° |
| `H` / `N` | Отразить H / V |
| `+` / `-` | Масштаб ×1.25 / ×0.8 |
| `0` | Заполнить холст |
| `Delete` | Удалить выделенное |

## 🎴 Hero Grid Editor

**`tools/hero-grid-editor.html`** — работа с **категориями** готовой сетки.

### Типы категорий

- **`heroes`** — плитка с героями (сетка по ID).
- **`text`** — любой текст/символ/строка. Именно сюда сохраняются результаты Line-Art и Pixel Editor.

Каждую категорию можно тащить, ресайзить, поворачивать, отражать, масштабировать, менять имя/координаты/тип/текст.

### Массовые операции

- `⌗ Область` — выделить прямоугольником.
- `Shift+клик` — добавить/убрать из выделения.
- `Ctrl+A` — выделить всё.
- `✂ Обрезать всё за границы` — подрезает категории за пределами 1193×593.

### Быстрое создание

- `+ Герои` — плитка на 12 героев (ID 1–12).
- `+ Текст` — одна текстовая категория.
- **`+ ASCII`** — умная кнопка: читает буфер обмена, разбивает текст по строкам/фрагментам и создаёт категории. Есть режимы: `по строкам`, `по 1/2/3/4/5 символов` и регулятор плотности.
- **Вертикальная линия** — задаёшь символы, количество, X/Y и получаешь столбец.
- **Картинки → символы** — быстрый встроенный конвертер для черновиков.

### Замена символов ASCII

Раздел «ASCII — символы» собирает все уникальные символы из ASCII-категорий. Каждому можно задать замену, потом нажать `ЗАМЕНИТЬ СИМВОЛЫ` или `• ЗАМЕНИТЬ ВСЁ НА ТОЧКИ`.

### Шрифт Radiance

Для превью 1:1 можно загрузить `radiance_regular.ttf` из `...\dota 2 beta\game\dota\resource\`.

### Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Ctrl+Z` | Отмена |
| `Ctrl+A` | Выделить всё |
| `Esc` | Снять выделение / выйти из режима области |
| `Delete` | Удалить выделенное |
| `Q` / `E` | Поворот −90° / +90° |
| `H` / `V` | Отразить H / V |
| `+` / `-` | Масштаб ×1.25 / ×0.8 |
| `0` | Заполнить холст |

## 📦 Формат JSON

Все инструменты пишут один и тот же формат:

```json
{
  "version": 3,
  "configs": [
    {
      "config_name": "Custom",
      "categories": [
        {
          "category_name": ".",
          "x_position": 120.5,
          "y_position": 84.0,
          "width": 30.0,
          "height": 30.0,
          "hero_ids": []
        }
      ]
    }
  ]
}
```

- `category_name` — для текста это сам символ, для героев — название группы.
- `x_position` / `y_position` — координаты в пикселях внутри 1193×593.
- `width` / `height` — 30.0 стандарт для одиночного символа.
- `hero_ids` — массив ID героев (пустой для текста).

### Как поставить сетку в Dota 2

1. Открой Dota 2.
2. `Настройки` → `Игра` → `Импорт сетки`.
3. Или в клиенте: `Сетки` → `Импорт`.
4. Или положить JSON в `...\dota 2 beta\game\dota\resource\grid\`.

## 🔄 Рабочие процессы

### Вариант А: из картинки

1. `lineart-converter.html` → загрузи PNG → подбери пресет.
2. Донастрой Blur/Threshold/gridStep/shading.
3. `💾 СКАЧАТЬ JSON`.
4. `pixel-ascii-editor.html` → перетащи JSON → появится на холсте.
5. Правь вручную, дорисовывай.
6. `💾 СКАЧАТЬ JSON` → готовый файл в Dota.

### Вариант Б: с нуля

1. `pixel-ascii-editor.html` → включи Safe Area и сетку.
2. Нарисуй рамку, расставь декор, оставь пустые зоны под героев.
3. `💾 СКАЧАТЬ JSON`.
4. `hero-grid-editor.html` → загрузи JSON → добавь категории «Герои» с ID.
5. `Экспорт JSON` → финальный файл.

### Вариант В: правка чужой сетки

1. `hero-grid-editor.html` → импортируй чужой JSON.
2. Выдели область → отмасштабируй / поверни / сдвинь.
3. Замени тексты.
4. Экспорт.

## 💡 Полезные мелочи

- **Работает офлайн** — чистый HTML+CSS+JS, никаких CDN и зависимостей.
- **Пресеты Line-Art** хранятся в localStorage. Экспортируй их в JSON, если чистишь браузер.
- **`║` и `═` нельзя** использовать в Dota — она рендерит их некорректно. В Pixel Editor есть кнопка для их массового удаления.
- **18 px** — оптимальный размер символа для Dota.
- **Симметрия H/V** в Pixel Editor удобна для орнаментов: включи и рисуй — всё дублируется зеркально.

## 🔒 Приватность

- Все инструменты работают **локально в браузере**.
- Никакие данные не отправляются на серверы.
- Нет аналитики, нет трекинга, нет внешних запросов.
- Загруженные изображения и JSON обрабатываются через `FileReader` и никогда не покидают вкладку.

# Dota 2 Grid Studio

Единый сайт-редактор на React + Vite для создания сеток героев Dota 2. Герои, рисование символами и конвертация изображений работают на **одном холсте, в одном документе, с общей историей изменений**.

Исходный проект: **[linsisss/dota2-grid-toolkit](https://github.com/linsisss/dota2-grid-toolkit)**. Студия объединяет его три инструмента; исходные страницы сохранены в `tools/`.

## Запуск

Нужен Node.js **22.19+**.

```sh
npm ci
npm run dev
```

Открой [localhost:4173](http://127.0.0.1:4173). Это сайт с модульной сборкой; открытие `index.html` через `file://` не поддерживается.

```sh
npm run build
npm run preview
```

Для публикации размести содержимое `dist/` на статическом хостинге. Относительные пути позволяют разместить сайт в подкаталоге. Серверная база данных и аккаунты не требуются; проекты и изображения обрабатываются в браузере.

## Онлайн-версия

После публикации через GitHub Actions студия будет доступна на [GitHub Pages](https://linsisss.github.io/dota2-grid-toolkit/). При первой настройке выбери **Settings → Pages → Build and deployment → Source: GitHub Actions**. Затем сайт будет собираться и публиковаться при каждом обновлении ветки `main`.

Исходные автономные инструменты также доступны отдельно:

- [Line-Art Converter](https://linsisss.github.io/dota2-grid-toolkit/tools/lineart-converter.html)
- [Pixel ASCII Editor](https://linsisss.github.io/dota2-grid-toolkit/tools/pixel-ascii-editor.html)
- [Hero Grid Editor](https://linsisss.github.io/dota2-grid-toolkit/tools/hero-grid-editor.html)

## Что умеет студия

- **Герои:** 127 героев в попапе с поиском по имени/ID и фильтрами по четырём атрибутам с оригинальными игровыми иконками. «Выбрать всех героев» добавляет всех из текущего фильтра одной операцией. На холсте — вертикальные игровые портреты с пропорциями, отступами и насыщенностью из Dota, название группы сверху, без подписей, уровней и значков на карточках. Выбери группу и нажми «+» после последнего портрета, по его вертикальному центру; в пустой группе «+» заменяет портрет.
- **Рисование:** отдельный черновик через «Рисование → В отдельном окне» с собственной отменой и добавлением результата одним слоем. Перо, умная кисть (`- | / \` по направлению движения), линии, фигуры, заливка, рамки, ластик, библиотека символов и симметрия. Один символ, последовательный или случайный набор; плотность может плавно нарастать или уменьшаться. Shift ограничивает штрих ближайшей осью.
- **Строки и выделение:** символы на одной высоте автоматически объединяются внутри слоя с сохранением точных промежутков. Лассо (`L`) выделяет по свободному контуру; после выделения можно перемещать объекты, удалять и выравнивать по левому краю, центру или правому краю. Один объект выравнивается относительно холста, несколько — относительно выделения.
- **Фон для обводки:** загрузка изображения на основной холст или в черновик с непрозрачностью 10% по умолчанию, настройкой положения, размера и видимости. Фон хранится в файле проекта, но не входит в Dota JSON.
- **Границы:** постоянное уведомление о символах вне 1193 × 593 и кнопка «Обрезать». Удаляются целиком только выходящие символы видимых разблокированных слоёв; операция отменяется.
- **Из арта:** исходный Canny-конвертер с утоньшением контуров, тенями, пресетами и живым предпросмотром в отдельном окне после выбора картинки. Все параметры доступны в этом окне: яркость, контраст, резкость, blur, порог, скелетизация, плотность, размещение, наборы символов и заливка. По умолчанию — 1000 символов. Кнопка «+» у набора открывает выбор категории и отдельных знаков. «Добавить на холст» создаёт отдельный ASCII-слой; «Отмена», крестик и Escape закрывают окно без изменения сетки.
- **Редактирование:** выделение рамкой, множественный выбор, перетаскивание, изменение размера за любой угол, сохранение пропорций при зажатом Shift, числовые координаты, копирование, дублирование и преобразование расположения.
- **Слои:** Фон / Герои / Декор и отдельный слой для каждого изображения или многострочного ASCII. Слои можно переименовывать, скрывать, блокировать, дублировать и удалять с отменой. Клик по ASCII выделяет рисунок целиком; Alt + клик — отдельный символ или строку. Дублирование и вставка скопированного арта создают новый слой. До 128 слоёв и 10 000 объектов на сетку.
- **Интерфейс:** SF Pro Display загружается как веб-шрифт, плавные анимации с поддержкой reduced motion. Рабочее пространство занимает высоту окна, холст вписывается автоматически; на узких экранах панели открываются кнопками. Под холстом — живой счётчик символов текста и рисунка (без пробелов и названий групп, включая скрытые слои).
- **Удобство:** отмена и повтор, автосохранение, шаблоны, привязка, масштаб, режим большого холста, горячие клавиши и адаптивный интерфейс.
- **Файлы с несколькими сетками:** импорт Dota JSON v3, постоянный список сеток, переименование и создание новых в том же файле — пустых или по шаблону. Правки сохраняются при переключении; экспорт включает все сетки и сохраняет неизвестные поля. Экспорт проверяет выход за границы, проблемные символы и количество категорий.

## Один рабочий процесс

1. Нажми **Загрузить JSON** и выбери свой `hero_grid_config.json`. Переключай сетки в списке **Сетки в файле** слева. Кнопка **+** рядом со списком добавляет новую сетку в этот же файл: пустую или по шаблону «По ролям» / «Мой пул».
2. Создай группу слева или справа, затем нажми «+» на холсте и выбери героев в попапе. Повторный клик убирает героя из группы.
3. На вкладке **Рисование** добавь символы, подписи или рамку.
4. На вкладке **ASCII** выбери изображение, настрой результат в открывшемся окне и нажми **Добавить на холст**.
5. Нажми **Скачать JSON** → **Скачать весь JSON**. Готовый `hero_grid_config.json` содержит все исходные и добавленные сетки с твоими изменениями.

## Два формата сохранения

| Формат                  | Для чего                                                                                                     |
| ----------------------- | ------------------------------------------------------------------------------------------------------------ |
| `hero_grid_config.json` | Для Dota 2. Видимые объекты превращаются в категории v3. Другие сетки из импортированного файла сохраняются. |
| `*.gridstudio.json`     | Для продолжения работы. Сохраняет объекты, слои, блокировки и черновики всех редактировавшихся сеток.        |

Автосохранение хранит проект в этом браузере на этом устройстве. Очистка данных браузера или завершение режима инкогнито могут удалить его. Для переноса и резервной копии используй **Сохранить проект** в окне экспорта или `Ctrl+S`.

Скрытые слои не экспортируются в Dota JSON, но сохраняются в проекте. История отмены, вручную выбранный шрифт и исходное изображение не сохраняются между запусками. Добавленные на холст символы сохраняются. Встроенные игровые шрифты подключаются автоматически при каждом открытии сайта.

## Как поставить сетку в игру

1. Закрой Dota 2.
2. Найди `Steam/userdata/<ID аккаунта>/570/remote/cfg/hero_grid_config.json` и сделай резервную копию.
3. Чтобы сохранить существующие сетки, сначала импортируй этот файл в студию и редактируй нужную сетку.
4. Помести экспортированный файл в эту же папку, запусти игру и выбери сетку в разделе героев.

Расположение файла также описано в [документации Dota Grid CLI](https://github.com/tvelich/dota-grid-cli#config-file). Корневая папка Steam зависит от установки.

Холст — **1193 × 593 px**, координаты экспортируются без зависимости от масштаба интерфейса. Подписи и ASCII используют встроенный **Radiance SemiBold**, 16 px, верхний регистр и игровые интервалы; для корейского текста подключён YDYGO 540 из Dota. Шрифт интерфейса — SF Pro Display. Высота области героев, строка заголовка и масштабируемые отступы рассчитываются по стилям игры. В **Превью** скрываются направляющие и включается тёмный игровой фон. Портреты статичные: косметические предметы и анимации из аккаунта не отображаются. JSON Dota не поддерживает произвольные цвета, размер шрифта или поворот отдельных глифов; преобразования меняют расположение и геометрию категорий.

## Горячие клавиши

| Клавиши                                   | Действие                                                   |
| ----------------------------------------- | ---------------------------------------------------------- |
| `V` / `B` / `T` / `R` / `E` / `L`         | Выделение / кисть / текст / прямоугольник / ластик / лассо |
| `Space` + перетаскивание                  | Перемещение увеличенного холста                            |
| `F`                                       | Большой холст / вернуть панели                             |
| `G` / `P`                                 | Сетка / превью                                             |
| `+` / `-` / `0`                           | Масштаб / вписать холст                                    |
| `Ctrl+Z` / `Ctrl+Shift+Z`                 | Отменить / повторить                                       |
| `Ctrl+A` / `Ctrl+C` / `Ctrl+V` / `Ctrl+D` | Выделить всё / копировать / вставить / дублировать         |
| `Ctrl+S` / `Ctrl+O`                       | Скачать проект / открыть файл                              |
| Стрелки / `Shift` + стрелки               | Переместить на 1 / 10 px                                   |
| `Delete` / `Esc`                          | Удалить / снять выделение                                  |
| `Shift` + перетаскивание угла             | Сохранить пропорции выделения                              |
| `/` / `?`                                 | Выбор героев / помощь                                      |

В текстовых полях работают обычные сочетания ввода. На macOS вместо Ctrl можно использовать Cmd.

## Разработка и проверки

```sh
npm run check
npm test
```

Автоматические тесты проверяют синхронизацию библиотек символов и сохранение исходных наборов символов в пресетах, импорт/экспорт, создание и редактирование нескольких сеток в одном файле, сохранение их черновиков и метаданных, валидацию, историю, независимость ASCII-слоёв, пропорциональное изменение размера за четыре угла, поворот расположения символов и его сохранение в Dota JSON, игровую геометрию карточек, Unicode-счётчик, конвертер и локальные портреты. Проверки также запускаются через GitHub Actions.

- [Архитектура](docs/architecture.md)
- [Проверки в браузере и перед выпуском](docs/qa.md)

## Приватность и лицензия

Аналитики, аккаунтов и отправки пользовательских файлов нет. SF Pro Display загружается с внешнего CDNFonts; файлы шрифта не включены в репозиторий. При недоступности CDN используется системный шрифт. JSON и изображения обрабатываются локально. Исходный код — [MIT](LICENSE). Dota 2 и изображения героев принадлежат Valve и не входят в MIT-лицензию исходного кода; см. [атрибуцию](assets/ATTRIBUTION.md).

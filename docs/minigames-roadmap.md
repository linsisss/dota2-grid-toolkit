# Мини-игры Crownfall: всё, что известно (план на будущее)

Запрос владельца 2026-10-16: «хочу добавить мини-игры из меню доты на сайт». В Dota это окно «Мини-игры для досуга во время поиска» (кнопка в панели «Играть» во время поиска матча). Сделано: страница `/minigames` и все девять игр (на dev, ночь 2026-10-16/17; ассеты пяти последних выгружены через DepotDownloader dota-loadout). Остальное отложено: «игры пока оставь». Как устроены страница и ядро — [minigames.md](minigames.md).

## Главное

- **Логика всех 9 игр — в C++ клиента Dota** (`client.dll`), не в Panorama-JS. Скрипты есть у двух игр, и логики в них нет: у «Рыбалки» — 31 строка (звук и анимация очков), у «Логова Зауга» — анимации экранов. Значит, каждую игру пишем заново на JS, а из игры берём графику, звук, тексты, разметку/CSS и **числа баланса** (vdata есть у 8 игр из 9; у «Подрывника Спуна» вместо vdata — таблица кадров и таймингов в CSS `@define`).
- Где чисел нет (ИИ, формулы очков, скорость шкал), подбираем по видео — см. «Видео» ниже.
- Награды, жетоны, таблица друзей, рекорды в Dota идут через сервер Valve (GC) — у нас свои: рекорд в браузере, пороги очков вместо жетонов.
- Полное исследование (карта файлов по каждой игре, вердикты, проверка скептиком, план): [minigames/research.json](minigames/research.json).

## Окно выбора (как в Dota)

`panorama/layout/popups/popup_dashboard_games.xml` + `.css`, корень — C++-тип `DOTADashboardGamesPopup`. 3 ряда по 3 ромба `.MinigameButton`, у каждого `onactivate="DOTACrownfallMinigameXxx()"`. Иконка — `opacity-mask` из `images/events/crownfall/overworld/nodes/icons/encounter_*_png` поверх `node_background_encounter(_inner)_png`; подписи — `DOTA_Crownfall_Archive_Minigame_*` в `dota_russian.txt`. Порядок: Рыбалка, Крылатые гонки, Сосулечный боец / Драконьи шахматы, Логово Зауга, Подрывник Спун / Замкобой, Сапёр Сплин, Терновый трон. Каждая игра — попап `panorama/layout/battle_pass/crownfall/bp_popup_crownfall_encounter_*.xml`.

## Ассеты: как достаём

- Скрипт PowerShell, который владелец запускает у себя (`iex …DownloadData('https://dev.gridstudio.me/gs-<случайное>.ps1')…`): сам находит Dota, **сам читает индекс `pak01_dir.vpk`** (обновления Dota не мешают), копирует нужные файлы по списку в zip на рабочий стол, карты-сцены (`game\dota\maps\scenes\crownfall\*.vpk`, вне pak01) — целиком. Генератор: [minigames/make-extract-ps1-base.py](minigames/make-extract-ps1-base.py) (список путей → .ps1) и [minigames/make-extract-ps1.py](minigames/make-extract-ps1.py) (вариант с картами). Скрипт кладётся на dev временно и удаляется после использования. Zip приходит через 0807.st.
- Уже выгружено (2026-10-16): 435 файлов для Сапёра, Спуна, Рыбалки, Гонок + 4 карты (`flappy_skywrath_act2{,_bg,_loop}.vpk`, `fishing_game_act1.vpk`) — список [minigames/extract-4games.txt](minigames/extract-4games.txt). Переведено в `assets/minigames/<id>/` скриптом `scripts/make-minigame-assets.mjs` (WebP, mp3, `data.json` из vdata, `sounds.json` из soundevents, строки RU/EN).
- Разбор: Source 2 Viewer CLI (`-d --recursive`): vtex_c → PNG, vsnd_c → wav/mp3, vdata_c → KV3-текст, vmdl_c → glb.
- **Альтернатива без ПК владельца:** в соседнем проекте `/home/code/dota-loadout` есть DepotDownloader со входом в Steam (`fetch-dota.mjs`) и 128 героев в glTF с анимациями. Владелец **разрешил** им пользоваться (2026-10-16).
- Тексты Valve (XML, CSS, JS, soundevents, локализация) — в зеркале https://github.com/spirit-bear-productions/dota_vpk_updates; декомпилированные vdata — в SteamDatabase/GameTracking-Dota2.

## Архитектура порта (из исследования)

- Каждая игра: `src/minigames/games/<id>/logic.mjs` (чистая логика, тесты) + вид (DOM/CSS с именами классов Valve для Сапёра; Canvas 2D с `imageSmoothingEnabled=false` для Спуна и Замкобоя; Canvas/WebGL для Гонок, Зауга, Трона; three.js для файтинга).
- Общее ядро `src/minigames/core/`: звук по таблице soundevents (WebAudio, громкость с 40 %, регулятор), рекорды, экраны, новелла (портреты и рамки `visual_novel/`, реплики `resource/localization/novels/crownfall_*.txt`).
- 3D-сцены (озеро, пещера гонок) — офлайн-рендер карт в картинки/ленты параллакса; модели — спрайт-листы.
- Эмулятор Panorama (`src/customize/panorama`) пока статичный; позже — живые `{d:}`-переменные, сниппеты, анимации, мини-`$`, тогда скрипты Valve (рыбалка, новелла) пойдут почти без правок.

## Права и риски

Логика не охраняется, но арт, музыка, голоса и логотипы — Valve; лицензии фан-сайтам нет. Реальный риск — просьба о снятии. Поэтому: все ассеты отдельно в `assets/minigames/` (чтобы быстро убрать), подпись «Фанатская реконструкция мини-игр Crownfall. Не связана с Valve. Графика и звуки — Valve Corporation.», без логотипа Dota, без рекламы на этих страницах, без имитации наград Valve. Музыка — самое чувствительное, её можно выключать.

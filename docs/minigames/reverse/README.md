# Разбор логики мини-игр Crownfall из client.dll

Логика девяти игр восстановлена по декомпиляции клиента Dota 2. Владелец разрешил реверс. Итоги разбора лежат
в файлах по играм: [chess](chess.md), [thorns](thorns.md), [zaug](zaug.md), [fighter](fighter.md),
[spoon](spoon.md), [fishing](fishing.md), [castle](castle.md), [race](race.md), [sweeper](sweeper.md).
В каждом пункте указаны правило, константы, адрес функции с выдержкой, уверенность, что делает порт сейчас и
что поменять. Код в `src/` по итогам разбора не менялся.

## Как делали

1. Скачали только `client.dll` и `server.dll` из депо 373303. Использовали DepotDownloader с сохранённым
   входом `dota-loadout`, файл-список, повтор с паузой:
   `DepotDownloader -app 570 -username <login> -remember-password -depot 373303 -filelist list.txt -dir bin`.
2. Подготовили индексы на Python без Ghidra (pefile + numpy, скрипты в scratchpad `re/scripts/`):
   - `schema.py` выгружает SchemaSystem: класс → поля со смещениями (1669 классов). По нему
     `*(int*)(def+0x750)` переводится в `m_nScorePerCellRevealed`.
   - `index.py` собирает RTTI: класс → vtable → виртуальные функции. Это даёт `Activate` каждой
     `CMatch3Ability_*`, `Think` модификаторов и т. д. Он же находит ссылки на строки: RIP-relative ссылки на
     ~16 тыс. строк (звуки, токены локализации, convar, поля vdata) с функцией-владельцем по `.pdata`.
   - `convars.py` достаёт значения convar по умолчанию из функций регистрации (`convars.tsv`).
3. Ghidra 12.1.4 headless (JDK Temurin 21.0.12): импорт и автоанализ заняли 36 мин при `-max-cpu 5` и
   куче 10 ГБ. Анализаторы выключали скриптом `PreOpts.java`: Decompiler Parameter ID, Non-Returning
   Functions – Discovered, Stack, Function ID, x86 Constant Reference, Call Convention ID, Apply Data
   Archives. С ними анализ шёл бы часами.
4. Декомпиляция:
   - `DumpParallel.java` (5 потоков) выгружает весь `.text` кусками по 1 МБ (≈300 МБ C, ~15 мин) и диапазоны
     игр.
   - `DecompServer.java` и `ghq.sh` — долгоживущий headless-сервер на копии проекта, отвечает на запросы
     «декомпилируй / покажи ссылки». Через него несколько разборщиков работали параллельно с одним Ghidra.
5. Игры разбирали параллельно, по выгрузкам. Где декомпилятор путал float, сверялись с дизассемблером
   (capstone).

## Как повторить после обновления Dota

1. Сравнить SHA-1 `client.dll` в свежем манифесте депо 373303 с таблицей выше. Если совпадает, разбор
   актуален.
2. Если не совпадает: скачать новый client.dll и снова прогнать `schema.py`, `index.py` и `convars.py`.
   Диффы `schema_client.txt` и `convars.tsv` сразу покажут новые и изменённые поля и значения.
3. Ghidra: `scripts/start.sh` (импорт и анализ, ~35 мин), затем `scripts/dump.sh <имя>:<начало>-<конец>`.
   Адреса сдвинутся, поэтому функции искать заново:
   - по строкам (`idx.xrefs.json`: звук `match3.lina.dragon_slave`, токен `#DOTA_Match3_ScoreEvent_*`, convar);
   - по vtable классов (`idx.vtables.json`).
   Эти якоря в разборах указаны рядом с адресами.
4. Сверить выдержки из разборов с новой декомпиляцией. Числа из vdata в разборах даны как имена полей, так что
   их проверять отдельно не нужно.

Рабочие файлы лежат в scratchpad сессии, в каталоге `re/`: инструменты, проект Ghidra, выгрузки C. В репозиторий
не кладутся. Диск: ~4,8 ГБ на пике, 3,3 ГБ осталось (Ghidra и JDK 1,2 ГБ, проект 1,5 ГБ, выгрузки 0,33 ГБ,
DLL 0,19 ГБ). Время: ~1,5 ч (анализ 36 мин, разбор игр параллельно ~25 мин).

## Что исправить в первую очередь (по влиянию на ощущение от игры)

1. **Шахматы: очки и способности.**
   - Очки: ряд даёт фиксированную сумму 50/100/200/500/1000 за 3/4/5/6/7+, без множителя комбо. Срабатывание
     самоцвета способности даёт +150/+450. Самоцветы, уничтоженные способностями, очков не дают.
   - Нова/LSA бьют мгновенно, без снарядов и задержек.
   - Chain Frost: 13 полётов, первый в противника.
   - Оглушение выбрасывает текущее действие противника; замедления складываются.
   - Улучшенный самоцвет появляется в «медиане» группы.
   - Гравитация 50 без предела скорости, подсказка через 5 с. → [chess](chess.md)
2. **Терновый трон.**
   - Повышение уровня предлагает только способности, сундук — выбор 1 из 3 предметов (комбинации первыми).
   - Цикл Империи: снаряды → порталы → метеоры каждые 4 с. Лучи только при ярости. Порталы закрываются
     через 15 с.
   - Урон касанием раз в 0,25 с от каждого врага, без неуязвимости.
   - Счёт = таблица событий × номер эшелона. → [thorns](thorns.md)
3. **Логово Зауга.**
   - ИИ босса: очередь состояний по двум фазам, бьёт по фиксированным точкам. Cold Embrace один раз при < 50 %,
     без лечения и призыва.
   - Узоры пуль: ширина × π, интервал на пулю, синус — одна полуволна.
   - Очки: 40 000 за жизнь, новые пороги рейтинга.
   - 5 жизней всего, неуязвимость 3 с.
   - Ответный залп при убийстве врага своего цвета. → [zaug](zaug.md)
4. **Замкобой.**
   - Сопротивление воздуха в порте ~60× сильнее, чем у Valve.
   - Запал гранаты считается от первого касания.
   - Скорость выстрела `max · min(max, charge) / 1600`.
   - Бонус за время не опускается ниже 300.
   - После правок перепроверить проходимость уровней. → [castle](castle.md)
5. **Сосулечный боец.**
   - Минимальная дистанция тел = сумма ширин героев.
   - Защита восстанавливается 3/с (20/с, когда сломана), без задержки.
   - Ходьба 6/5, старт ±500, окна ввода по 8 кадров на шаг.
   - Счёт: добавить урон/2, бонус за 2–0, новая формула времени.
   - ИИ — дерево решений Valve. → [fighter](fighter.md)
6. **Рыбалка.**
   - Улов — ближайшая из 8 рыб пруда; шансы категорий задаются на каждую рыбу.
   - Строки счёта: QuickCast 200 за 1 с; Perfect и Final по +10 %; «Уникального улова» нет.
   - Физика полосы ±84, срыв при энергии −1, новая формула сложности. → [fishing](fishing.md)
7. **Подрывник Спун.**
   - Состав врагов: 6 с 3-го этапа, золотые на 7-х. Обычные враги ставят бомбы.
   - Скорости ИИ 1,5/4,5 клетки/с.
   - Цепь ×1/×2/×4 за 0,45 с.
   - Бомбардировщики по этапам.
   - Возрождение на месте; по таймауту враги убираются и даётся 60 с. → [spoon](spoon.md)
8. **Крылатые гонки.**
   - Проём постоянный 450, без ограничения сдвига.
   - ИИ Бэтрайдера: взмах, если ниже кромки камня + 150.
   - Удар: −200 скорости и 0,5 с без управления.
   - +45 из видео — это ×1,5 только в бесконечном режиме. → [race](race.md)
9. **Сапёр.**
   - Предметы: один бросок на каждую соседнюю закрытую клетку за этап (4 %, иначе 3 %); на мины класть можно.
   - Любой ЛКМ тратит клик предметов.
   - Перескок с флага: −1 клик, сначала к открытым.
   - «Отдых» блокирует только аккорды.
   - Первый клик: ноль, ≥ 10 % поля, не прямоугольник. → [sweeper](sweeper.md)

## Что не найдено (сводка)

- **chess:** запись события «Противник побеждён» (сумма, скорее всего `m_nCompletionScore`); экранная точка
  противника для пути Dragon Slave.
- **thorns:** неуязвимость при рывке, `m_flKnockbackDuration` по умолчанию, сумма «Мешочка с золотом».
- **zaug:** направление оси y (принято вниз, как в порте), скрытый режим одиночного выстрела.
- **fighter:** смысл `m_nCancelDuration`, итог «Конец игры» при проигрыше (вероятно, ошибка Valve).
- **spoon:** враг «Eater» (в розничной сборке нет), флаг перехода к бесконечному режиму.
- **race:** момент звука ускорения.
- **fishing:** точный код стайного плавания рыб (известны только константы).
- **castle:** разброс суббоеприпасов, наведение мышью.

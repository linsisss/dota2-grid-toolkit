# «Драконьи шахматы» (chess, Valve: match3) — разбор client.dll

Бинарник: client.dll 107 533 976 байт, SHA-256 dfec84e4…ceefd6, депо 373303, манифест 5121451448605799518
(2026-10-15). Адреса — виртуальные (база 0x180000000), имена функций — Ghidra (`FUN_<адрес>`).

Где логика: всё поле и бой — в диапазоне 0x182b78000–0x182bd0000. Обработчик ряда — `FUN_182b87fc0`
(вызывается детектором `CMatch3BoardModifier_MatchDetector` 0x182b95600 для каждой группы), способности —
второй слот vtable классов `CMatch3Ability_*`, урон — `FUN_182babfe0` (Unit::TakeDamage), лечение —
`FUN_182bac190`, ход противника — `FUN_182bcad70` (CMatch3Opponent::Think), очередь действий — `FUN_182bcd680`,
табличка очков — `FUN_1829442f0` (попап). Слоты модификаторов юнита (vtable `CMatch3UnitModifier`):
+0x18 «запрет лечения», +0x20 «снижение лечения %», +0x28 оглушение, +0x30 безмолвие, +0x38 замедление %,
+0x40 иммунитет к магии, +0x48 иммунитет к физ. урону, +0x50 вампиризм %.

## 1. Очки: фиксированные суммы по событиям, без множителя комбо

- Правило. Счёт = сумма «ScoreEvent»:
  - ряд (тип 1): по числу самоцветов в группе (`*param_2`): 3 → 50, 4 → 100, 5 → 200, 6 → 500, 7+ → 1000;
  - сработал самоцвет обычной способности (тип 3) → 150; мощной (тип 4) → 450 (за каждый такой самоцвет
    в собранной группе или уничтоженный способностью);
  - победа над противником (тип 2) — отдельное событие (место записи не найдено, см. конец).
  - Самоцветы, уничтоженные способностями, очков не дают (это «группа» из 1 самоцвета, порог `> 2`).
- Комбо (`+0x168`) растёт на 1 за каждую группу и сбрасывается, когда все самоцветы снова неподвижны
  (`CMatch3BoardModifier_ComboReset` 0x182b94e00); оно выбирает только звук `piece_matched(.2…8)`.
- Доказательство: `FUN_182b87fc0`, хвост функции; попап суммирует `*(param_1+0xe0) += amount`.
  ```c
  if (iVar6 == 3) uVar27 = 0x32; else if (iVar6 == 4) uVar27 = 100;
  else if (iVar6 == 5) uVar27 = 200; else if (iVar6 == 6) uVar27 = 500; else uVar27 = 1000;
  ... *(undefined4 *)(lVar8 + lVar16) = 1;  *(undefined4 *)(lVar8 + 4 + lVar16) = uVar27;
  ... = 3; ... = 0x96;   /* SuperPieceTriggered, 150 */   ... = 4; ... = 0x1c2; /* Ultra, 450 */
  ```
- Уверенность: высокая (тип 2 — средняя).
- Сейчас в порте: `POINTS_PER_PIECE = 10` × ступень комбо за каждый самоцвет (`resolveMatch`, `clearPiece`),
  плюс 10 за каждый самоцвет, уничтоженный способностью.
- Что поменять: в `resolveMatch` начислять одну сумму за группу по таблице 50/100/200/500/1000; комбо оставить
  только для звука; в `clearPiece` для `cause !== 'match'/'merge'` очков не давать; при касте способности от
  самоцвета `super` +150, `ultra` +450 (в `cast` или в месте вызова). Рубежи 5 000/40 000 не трогать.

## 2. Где появляется улучшенный самоцвет

- Правило. Из самоцветов группы, которые сейчас можно собирать, берётся тот, у кого сумма манхэттенских
  расстояний до всех остальных минимальна (первый при равенстве, порядок — как в группе). Сдвинутый самоцвет
  роли не играет. 4 самоцвета → `SuperPiece`, 5+ → `UltraPiece` (`FUN_182ba9450(…, 4 < count)`), остальные
  получают `Merging` к нему. Удар по противнику (снаряд) летит от каждого самоцвета группы, включая центральный.
- Доказательство: `FUN_182b87fc0`:
  ```c
  fVar30 = fabs(x - x2); fVar31 = fabs(y - y2); fVar32 = fVar30 + fVar32 + fVar31;   /* по всем */
  if ((lVar16 == 0) || (fVar32 < fVar33)) { lVar16 = lVar8; fVar33 = fVar32; }
  ```
- Уверенность: высокая.
- Сейчас в порте: последний сдвинутый самоцвет, иначе середина самого длинного ряда.
- Что поменять: выбирать «медиану» по сумме |dx|+|dy| (для 4 в ряд — второй с начала, для 5 — центральный,
  для L/T — угол/перекрестие).

## 3. Урон

- Каждый самоцвет группы → снаряд `MatchAttack` (скорость convar 15 клеток/с, самонаводится на противника),
  при попадании `TakeDamage(тип 1 = физ., 1.0)`. Если урон прошёл и у пользователя есть вампиризм (сумма слота
  +0x50, Insatiable Hunger = 200), лечение = урон × % / 100 (2 HP за самоцвет). `FUN_182b90c50`.
- `TakeDamage(тип, x)`: тип 1 не проходит при любом модификаторе с иммунитетом к физ. урону (Cold Embrace),
  тип 2 — при иммунитете к магии (BKB); иначе здоровье −= x (без округления).
- Атаки противника: обычная — `RandomFloat(min_damage, max_damage)`, физ.; крит — `RandomFloat(min,max) ×
  crit_percent / 100`; **Hypothermia бьёт магическим уроном (тип 2)** — Cold Embrace её не блокирует.
  Снижение лечения Hypothermia: один модификатор, % += heal_reduction_percent (не выше 100), длительность
  обновляется. Лечение: `(1 − Σ снижений/100) × x`, ноль при Ice Blast (`FUN_182bac190`).
- Периодический урон (Ice Blast, Cold Feet, Icefire): тик раз в `damage_interval`, каждый тик
  `damage / floor(duration / interval)`, магический (`FUN_182b9a150`, `FUN_182b99a40`).
- Уверенность: высокая.
- Сейчас в порте: целочисленный `randInt` и `Math.round` для крита; `hypothermia` в списке `PHYSICAL`.
- Что поменять: урон — float (`min + random × (max − min)`), округлять только в цифрах на экране; убрать
  `hypothermia` из `PHYSICAL`.

## 4. Геометрия и тайминг способностей

Общее: «уничтожить самоцвет» = `FUN_182b891b0` — самоцвет обрабатывается как группа из одного: он исчезает,
**бьёт противника снарядом на 1 урона**, а если это самоцвет способности — срабатывает его способность
(+150/450 очков); очков за сам самоцвет и роста комбо нет. Цели выбираются среди самоцветов, которые сейчас
можно собирать (`FUN_182bb8ee0`: ни один модификатор не мешает), включая самоцветы способностей и свои.

## 5. Ход противника, замедления, оглушения

- Очередь: у противника до 3 действий в очереди (`FUN_182bcd680` дозаполняет по кругу
  `m_vecRepeatingActions`); считается только перезарядка первого (`+0x28`).
- Время противника: `dt × 1 / clamp(1 + Σ slow% / 100, 0.1, 10)` (`FUN_182bb2c60`). Каждое замедление —
  **отдельный модификатор** со своим таймером, проценты **складываются** (Crystal Nova 50 + Frost Nova 100 →
  ×1/2,5).
- Оглушение: пока есть любой модификатор оглушения, время стоит и текущее действие помечается прерванным
  (`+0x20`). Когда оглушение кончилось, **прерванное действие выбрасывается** (`FUN_182bcd620`), и
  начинается перезарядка следующего по кругу. Оглушения не складываются по времени — каждое своё.
- BKB: модификатор иммунитета к магии на `duration`; уже наложенные оглушения/замедления **не снимает**
  (под BKB просто не накладываются новые, кроме замедления Frost Nova).
- Удар атакующих действий приходит по событию анимации (`CMatch3OpponentAction_AttackBase`: состояние 1 → 2,
  когда время анимации ≥ `+0x38`), т. е. задержка задаётся анимацией — наше 0,35 с остаётся приближением.
- Доказательство: `FUN_182bcad70`:
  ```c
  if (stunned) { *(char *)(front + 0x20) = 1; return; }
  if (*(char *)(front + 0x20) != '\0') FUN_182bcd620(param_1);      /* выбросить прерванное */
  fVar7 = FUN_182bb2c60(param_1) * dt;  /* 1/clamp(1+sum/100, 0.1, 10) */  cooldown -= fVar7;
  ```
- Уверенность: высокая.
- Сейчас в порте: `tickOpponent` — после оглушения перезарядка того же действия заново; `slowOpponent`
  держит одно замедление с максимумом процентов; BKB снимает stun и slow.
- Что поменять: после оглушения `setAction(game, actionIndex + 1)`; замедления — список, сумма процентов,
  множитель `1 / clamp(1 + sum/100, 0.1, 10)`; BKB ничего не снимает; Frost Nova вешает замедление и под BKB.

## 6. Поле: гравитация, новые самоцветы, подсказка

- Падение: скорость += 50 клеток/с² × dt (dt умножен на время пользователя, т. е. делится на
  `clamp(1 + Σ slow%/100, 0.1, 10)` от Frost Attack), **без ограничения скорости** (`FUN_182bcbfd0`).
- Новые самоцветы: в каждом столбце недостающие появляются над самым верхним самоцветом столбца с шагом
  ровно 1 клетка (`y = min(0.5, верхний) − 1`), герой — `RandomInt` равновероятно, **без защиты от готовых
  рядов** (каскады возможны) (`CMatch3BoardModifier_NewPieces` 0x182b95b00).
- Подсказка: через 5,0 с после того, как поле успокоилось (`*(param_2+0x138) <= t + 5.0`,
  `CMatch3BoardModifier_MatchHints` 0x182b957d0).
- Уверенность: высокая.
- Сейчас в порте: `GRAVITY = 60`, `MAX_FALL = 16`, шаг новых 1,05, `HINT_DELAY = 6`.
- Что поменять: `GRAVITY = 50`, убрать `MAX_FALL`, шаг 1,0, `HINT_DELAY = 5`.

## 7. Модификаторы пользователя от противника

- Cold Feet: снимается после `match_count` групп из 3+ (`FUN_182b99b50`: `2 < *param_4`), иначе по
  окончании — оглушение `stun_duration`. Совпадает с портом.
- Frost Attack: замедление поля через тот же множитель времени (`+0x38` слот) — совпадает (×4 при 300 %).
- Hypothermia — см. п. 3.

## Не найдено / не проверено

- Где записывается событие очков «Противник побеждён» (тип 2) и его сумма: потребитель в попапе есть
  (`FUN_1829442f0`), запись — вне просмотренных функций. Порт даёт `m_nCompletionScore` уровня — оставить.
- Точная экранная позиция противника на поле (`+0x58` юнита задаётся сценой) — нужна для пути Dragon Slave.
- Стартовое поле: генерируется тем же `NewPieces` (случайно, с возможными рядами) — не проверено, когда
  именно они схлопываются до отсчёта; порт строит поле без рядов — можно оставить.

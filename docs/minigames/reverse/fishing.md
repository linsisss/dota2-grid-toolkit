## 1. Откуда берётся улов (шансы категорий, влияние заброса)

- Правило. Улов не разыгрывается при поклёвке. В начале каждой приманки (вход в PreCastAimRod) все 8 рыб
  пруда (`fish0…fish7` карты) получают категорию, вес и вариант; при падении поплавка (вход в WaitingForBite)
  ловится **ближайшая к поплавку активная рыба**, на любом расстоянии (`FUN_18292bd30`, case 8).
- Раскладка, по рыбам в порядке индекса, `r = U(0,1)`, счётчики «уже есть UR / Rare» общие на пруд:
  ```
  если акт 1 и рекорд ≤ 499 (новичок): категория Common, w = U(0,0.7)·U(0,1)   (без мусора и редких)
  иначе: w = U·U  (если уже >2 рыб с w>0.6, ещё ×U)
    r < pUR  и UR ещё нет     → UltraRare, если w<0.7: w = U(0.7,1)
    иначе r < pR и Rare ещё нет → Rare,      если w<0.7: w = U(0.7,1)
    иначе r < 0.5             → Uncommon
    иначе                     → Common; если w>0.6: w = U(0,0.6); если w<0.15: Trash, w = 0
  pUR = 0.05, pR = 0.15 (акт 1); 0.1 / 0.3, если `+0x60` == 2 (акт II)
  ```
  Итого в пруду не больше одной UR и одной Rare; среди «обычной» половины ≈46 % мусора (w<0.15). Вид внутри
  категории — равновероятно из видов vdata этой категории (`FUN_181d7ff10`).
- Место: центр пруда = точка героя + направление вперёд × (400 + 650·0.5 = 725); рыба: x + U(−450, 450),
  y + U(−250, 250); UR/Rare/вариант (любая «особая») — ещё **+200 по y**. Дальше рыбы плавают стаей вокруг своих
  точек: 70 ед/с, вариант 140 (±10 по индексу), сближение в радиусе 190, расталкивание в 90, возврат к своей
  точке дальше 300 (`FUN_182942db0`). Так дальний заброс чаще попадает рядом с особыми рыбами — других
  поправок от силы заброса нет.
- Константы: см. псевдокод; `dota_crownfall_fishing_cheat_big_fish_only` → w = 1.
- Доказательство: `FUN_182925dd0`:
  ```c
  fVar21 = 0.15; fVar24 = 0.05; if (*(char *)(param_1 + 0x60) == '\x02') { fVar21 = 0.3; fVar24 = 0.1; }
  if ((499 < *(int *)(param_1 + 0xe4)) || (bStackX_8 = 1, *(char *)(param_1 + 0x60) != '\x01')) bStackX_8 = 0;
  ... if ((fVar24 <= r) || (0 < nUR)) { if ((fVar21 <= r) || (0 < nRare)) { if (0.5 <= r) {
        cat = 2; if (0.6 < w) w = RandomFloat(0,0.6); if (w < 0.15) { cat = 1; w = 0.0; } } else cat = 3; }
      else { cat = 4; if (w < 0.7) w = RandomFloat(0.7,1.0); ... } } else { cat = 5; ... }
  fStack_104 = RandomFloat(-250,250); if (special) fStack_104 += 200.0;   fVar21 = RandomFloat(-450,450);
  ```
- Уверенность: высокая (правила); средняя — что мировой +y совпадает с «вперёд от героя» в нашей сцене.
- Сейчас в порте: `pickCatch` (l.79) — таблица `odds` 10/34/26/21/9 с поправкой на силу, вид случайный.
- Что поменять: моделировать пруд: на каждую приманку разложить 8 рыб по правилу выше (со своими точками),
  при падении поплавка брать ближайшую. Минимум без стайного плавания — ближайшая из 8 к точке падения по
  домашним точкам. Режим новичка — пока рекорд < 500.

## 2. Варианты (Блестящий / Сверкающий)

  вариант = `U < 0.2 ? 2 : 1` (80 % «Variant1», 20 % «Variant2»), w = max(w, 0.25), рыба «особая» (+200 по y).
- Доказательство: `FUN_182925dd0`:

  ```c
    nVar++; if (w < 0.25) w = 0.25; special = true;
  ```

- Уверенность: высокая.
- Сейчас в порте: `variantOdds: [0.08, 0.03]` на пойманную рыбу.
- Что поменять: шанс варианта 20 % на рыбу пруда (из них 1/5 — второй вариант), не больше 2 на пруд.

## 3. Вес и класс веса

- Правило. Мин./макс. вес вида = `m_flAverageWeight × 0.8 / × 1.2` (при загрузке vdata); вес улова
  `kg = min + (max − min)·w`. Класс по w: `<0.1` Tiny, `<0.4` Small, `<0.6` Average, `<0.9` Large, иначе Huge.
  Распределение w — §1 (U·U, у редких ≥0.7, у вариантов ≥0.25).
- Доказательство: `FUN_181d8c750` `*(fish+0x30) = avg*0.8; *(fish+0x34) = avg*1.2;`, `FUN_18291ad30`
  `0x394 = (max-min)*w + min`, `FUN_182910750` `if (0.1 <= w) { if (0.4 <= w) { if (0.6 <= w) {… 0.9 …`.
- Уверенность: высокая.
- Сейчас в порте: `ratio = 0.8 + 0.2·(U+U)`, `weightClass` (l.65) с порогами 0.85/0.95/1.05/1.15 по ratio
  (= w 0.125/0.375/0.625/0.875).
- Что поменять: хранить w, `ratio = 0.8 + 0.4·w`, классы по w (0.1/0.4/0.6/0.9).

## 4. Сложность рыбы

- Правило. `D = m_mapCategoryToDifficulty[cat] + (variant ? 7 : 0) + 5·w + m_flBonusDifficulty`
  (во fishing1 бонус у всех 0). Отсюда: сила рывка `4·D + 20`, шанс рывка за кадр `0.013 + 0.0015·D`.
  Окно подсечки: `escape_min + (escape_max − escape_min)·(1 − w)` = 0.7…1.5 с (тяжёлая — короче).
  Флаги разметки: BigFish (w>0.7), SmallFish (w≤0.25), RareFish (UR).
- Доказательство: `FUN_18291ad30`:
  ```c
  fVar16 = (variant == 0) ? 0.0 : 7.0;   fVar14 = w * 5.0;
  D = fVar16 + catDiff + fVar14 + fish->m_flBonusDifficulty;
  ConMsg("Fish Difficulty: %f + %f + %f + %f = %f\n", catDiff, fVar16, fVar14, bonus, D);
  *(float *)(p + 0x3f4) = *(float *)(p + 0x400) = D * 4.0 + 20.0;   *(float *)(p + 0x3e4) = D * 0.0015 + 0.013;
  *(float *)(p + 0x3d8) = esc_min + (esc_max - esc_min) * (1.0 - w) + bite;
  ```

- Уверенность: высокая.
- Сейчас в порте: `fishDifficulty` (l.73): cat + (ratio−1)·5 + variant·0.5 + U·0.5.
- Что поменять: формула выше (вариант даёт +7 — UR-вариант с w=1 имеет D = 19).

## 5. Заброс: прицел, сила, полёт

- Прицел (состояние 3; в 4 заморожен): угол `a` от мыши; при `|a| > 0.8·aim_fov/2 = 20°`
  `a = sign·(20 + sqrt(|a| − 20))`, затем ограничение ±(25 + 5) = ±30°.
- Сила: начинается с 1, растёт на 50/с, пока кнопка держится; при превышении `max_cast_strength` = 80 —
  **заброс сам**, с флагом Max Power. Отпускание раньше — заброс с текущей силой. Доля `p = сила/80`
  (1/80…1), дальность `400 + 650·p`. До полной — (80−1)/50 = 1.58 с.
- Полёт: CastingRod → WaitingForBite, когда `t > 0.4 + (0.5 + 0.5·p)` (0.4 — замах Венги; у Скайрата 0.9).
  `cast_rod_anim_time` в попапе не читается.
- Доказательство: `FUN_182945500`, `FUN_182931230` case 5:
  ```c
  fVar8 = dt * *(float *)(p + 0x3ac) + *pfVar3;            /* 0x3ac = 50, старт 0x3a8 = 1 */
  if (fVar8 <= max_strength) { charging = 1; } else { *pfVar3 = max_strength; *(p + 0x3b0) = 1; SetState(5); }
  *(float *)(p + 0x214) = fVar7 * 0.5 + 0.5;  *(p + 0x210) = skywrath ? 0.9 : 0.4;
  case 5: if (t <= *(float *)(p + 0x214) + *(float *)(p + 0x210)) break; SetState(8);
  ```
- Уверенность: высокая.
- Сейчас в порте: `chargeTime 1.5` от 0, шкала стоит полной; `castAnim 0.5 + flight 0.55`; прицел ±25° жёстко.
- Что поменять: сила 1→80 по 50/с с автозабросом на 80; полёт `0.4 + 0.5 + 0.5·p`; мягкий край прицела.

## 6. Поклёвка, ложный всплеск, «рано/поздно»

- Правило. В Ready: `bite = U(bite_min 2.5, bite_max 6.5)`, `fake = U(2.5, bite) − 0.75`. В WaitingForBite
  (таймер с нуля): клик до `bite` → промах «рано» (причина 0); клик в `[bite, deadline)` → подсечка (сразу
  ReelingFish); клик после `deadline` → «поздно» (1); без клика — «поздно» при `t > deadline + 3`.
  `deadline = bite + 0.7 + 0.8·(1 − w)`. Ложный всплеск один, в момент `fake`, и только если w > 0.5.
- Доказательство: `FUN_1829256f0`, `FUN_182901c70` case 8, `FUN_182931230` case 8, `FUN_182941930`:
  ```c
  0x3d0 = RandomFloat(bite_min, bite_max);   0x3d4 = RandomFloat(bite_min, 0x3d0) - 0.75;
  if ((t < bite) || (deadline <= t)) { reason = (bite <= t); SetState(0xb); } else SetState(9);
  case 8: if (t > deadline + 3.0) { reason = 1; SetState(0xb); }
  ```
- Уверенность: высокая (порог ложного всплеска w>0.5 — средняя: визуальная ветка).
- Сейчас в порте: окно 0.7…1.5 случайно, ложные всплески каждые 0.9…2.4 с, «поздно» сразу по окну.
- Что поменять: окно от веса, один ложный всплеск у тяжёлых, авто-«поздно» через 3 с после окна.

## 7. Рыба в шкале ловли

- Правило (каждый кадр Update, единицы шкалы 0…100, `t` — время вытягивания):
  ```
  старт: pos = shown = 0, v = 4D+20, dir = +1
  если U < 0.013+0.0015·D  или  t − lastImpulse > 2:
     если shown < 5: dir = +1;  иначе если shown > 95: dir = −1
     иначе если U < pRev и t > lastRev + 0.5: dir = −dir, lastRev = t
        (pRev = 0.65, если рыба плывёт от середины: dir>0 и shown≥50 или dir<0 и shown<50; иначе 0.1)
     tire = t > 7 ? 1 − min(0.1·(t−7), 0.5) : 1
     v = U(0.5,1)·tire·(4D+20)·dir;  lastImpulse = t
  pos += v·dt;  v ×= 0.99 (за кадр);  у края pos зажат в [0,100] и v ×= −0.7 (отскок)
  shown += (pos − shown)·0.5         (в полосе проверяется shown)
  ```
- Доказательство: `FUN_182945930`:
  ```c
  if ((RandomFloat(0,1) < p3e4) || (2.0 < t - lastImp)) { ...
    if (t > tire) fVar10 = 1.0 - min((t - tire) * 0.1, 0.5);
    *(p + 0x400) = RandomFloat(0.5,1.0) * fVar10 * (D*4+20) * dir; }
  v = *(p+0x400); *(p+0x400) = v * 0.99; pos = v * dt + pos;
  if (pos < 0) { pos = 0; if (v*0.99 < 0) *(p+0x400) = v*0.99 * -0.7; }  /* так же у верха */
  shown = (pos - shown) * 0.5 + shown;
  ```
- Уверенность: высокая. Частота кадров: множители «за кадр» (0.99, шанс рывка, 0.5) зависят от FPS Panorama.
- Сейчас в порте: `reel` (l.211) — цели и подбор скорости `6+5.5D`, усталость ×0.6 после 7 с.
- Что поменять: перенести алгоритм как есть, шаг фиксированный 1/60 с (по кадру Valve рассчитывал на ~60 FPS).

## 8. Полоса ловли (физика)

- Правило. Размер `catch_bar_size + per_miss·промахов` = 24 + 3·n. Держать — a = +84 ед/с², отпустить — −84.

  Низ: `x = 0`, если v<0 — `v ×= −0.3` (отскок). Ограничения скорости нет. Старт x = 0, v = 0.
- Доказательство: `FUN_182945930`:

  ```c
  fVar5 = holding ? 84.0 : -84.0;  v = fVar5 * dt + v;  x = fVar5*0.5*dt*dt + v*dt + x;
  if (0 < x) { if (barMax < size + x) { x = barMax - size; if (0 < v) v = v * 0.9; } }
  else { x = 0; if (v < 0.0) v = v * -0.3; }
  ```

- Уверенность: высокая.
- Сейчас в порте: +100/−80 %/с², предел 65 %/с, на краях скорость в ноль.
- Что поменять: ±84, без предела, верх ×0.9, низ отскок ×−0.3.

## 9. Энергия улова и Perfect

- Правило. Энергия стартует с `catch_energy_initial` 2. Рыба в полосе (`shown` в `[x−0.0001, x+size+0.0001]`):
  энергия += dt, таймер вне полосы = 0. Вне полосы: таймер += dt; когда он ≥ grace 0.25 — энергия −= dt и
  снимается флаг Perfect. Поймана при энергии **> 5.5**, сорвалась при **< −`catch_energy_fish_escape`** = −1.
  AlmostCaught — при энергии > 5.1.
- Доказательство: `FUN_182945930`:
  ```c
  if (out) { outT += dt; if (grace <= outT) { perfect = 0; energy -= dt; } } else { outT = 0; energy += dt; }
  if (needed < energy) SetState(10); else if (energy < -escape) { reason = 2; SetState(0xb); }
  ```
- Уверенность: высокая.
- Сейчас в порте: сорвалась при 0; Perfect снимается при любом выходе из полосы.
- Что поменять: порог срыва −1; Perfect снимать только после 0.25 с вне полосы.

## 10. Очки улова (GenerateScore)

- Строки по порядку (`FUN_182910750`), «%» — процентная строка от накопленной суммы:

  | Строка | Условие | Очки |
  |---|---|---|
  | Rarity | всегда | Trash 100, Common 200, Uncommon 500, Rare 800, UltraRare 1000 |
  | Variant | вариант | 1 → 750, 2 → 1500 |
  | Weight | не мусор | `100 + trunc(1400·w)` (100…1500) |
  | TrashBonus | мусор | 100 |
  | FirstCatch | приманка №1 (индекс 0) | 100 |
  | CatchStreak3/4/5 | подряд пойманных, считая эту: 3/4/5 | 100 / 250 / 400 |
  | MaxPower | сила дошла до 80 (автозаброс) | 200 (песок: 500) |
  | QuickCast | зарядка начата < 1 с после входа в PreCastAimRod | 200 (песок: 300) |
  | FinalCatch | последняя приманка (`num_lures − 1`) | **+10 %** |
  | PerfectCatch | Perfect не снят | **+10 %** |

  Итог: `sum += row.percent ? floor(row.value·sum/100) : row.value` по порядку (FinalCatch считается раньше
  PerfectCatch). Затем `× dota_crownfall_fishing_score_multiplier` (1.0) — только если `FUN_1816af900()`
  (сравнение кода вселенной/приложения с 0x330, т. е. внутренние сборки); в обычном клиенте не действует.
  Строки «Уникальный улов» в клиенте нет (токенов Unique/FastCast нет вовсе); «Забота о чистоте» —
  это TrashBonus = 100.
- Доказательство: `FUN_182910750`:
  ```c
  if (cat == 1) v = 100; else if (cat == 2) v = 200; ... else if (cat == 5) v = 1000;
  *(int *)(row + 0x18) = 100 - (int)(w * -1400.0);                         /* Weight */
  if (*(char *)(p + 0x412)) { v = 300; if (!sand) v = 200; }               /* QuickCast */
  if (idx == num_lures - 1) { v = 10; percent = 1; }                       /* FinalCatch */
  if (*(char *)(p + 0x411)) { v = 10; percent = 1; }                       /* PerfectCatch */
  do { v = row.v; if (row.pct) v = (v * sum) / 100; sum = v + sum; } while (...);
  ```
  QuickCast: `FUN_182901c70` case 3 `quick = (t <= 1.0 && t != 1.0); ConMsg("Started casting before 1s…")`.
- Уверенность: высокая.
- Сейчас в порте: `scoreCatch` (l.167): Trash 0 + бонус 300, Perfect +200, QuickCast 100 за 2.5 с,
  Unique 250, MaxPower по `power ≥ 0.999`; FinalCatch +10 % от всей суммы в конце (совпадает только без Perfect).
- Что поменять: таблица выше; убрать Unique; Perfect → +10 % после FinalCatch; QuickCast 200 и окно 1 с от
  начала прицеливания; Trash: 100 + 100 без строки веса.

## 11. Прочие тайминги и итог

- Ready → PreCastAimRod по нажатию; поймано → карточка: 1 с (`caught_fish_anim_time`) + 1 с
  (`post_catch_anim_time`), дальше по нажатию после анимации строк (`0x434`); улов > 1100 очков → состояние 14
  (большой улов) перед следующей приманкой. Промах → дальше через 0.25 с после реплики или по нажатию после 1 с.
- 5 приманок заданы в коде (`+0x41c = 5`), convar `num_lures` — только для FinalCatch и ширины полосы.

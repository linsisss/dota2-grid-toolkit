## 1. Ускорение (+30 или +45)

- Правило: скорость `+= flAcceleration·dt` (30). **В бесконечном режиме, пока Бэтрайдер впереди**,
  ускорение **×1,5 = 45**. Бэтрайдер в бесконечном режиме невидим, но симулируется (п. 3). Он стартует
  рядом и первые секунды обычно чуть впереди. Отсюда «+45» на видео бесконечного режима. В гонке всегда
  +30. После удара (0,5 с) ускорения и гравитации нет. Скорость ограничена `[flMinimumSpeed, flMaxSpeed]`
  = [50, 560].
- Константы: 30; ×1,5; 50; 560.
- Доказательство: `FUN_18293d690`:
  ```c
  accel = def->flAcceleration; grav = game->flGravity;
  if (hurt <= 0) { if (endless && player.x < bat.x) accel *= 1.5; }
  else { grav = 0; accel = 0; }
  vel += (accel, grav) * dt;  vel.x = clamp(vel.x, flMinimumSpeed, def->flMaxSpeed);
  ```
- Уверенность: высокая (код). Средняя — что `0x330` именно бесконечный режим: так следует из трёх
  независимых мест.
- Сейчас в порте: `move` (logic.mjs:159–174) — всегда +30; в бесконечном режиме Бэтрайдера нет
  (logic.mjs:194).
- Что поменять: в бесконечном режиме симулировать невидимого Бэтрайдера и умножать ускорение на 1,5,
  пока `opponent.x > player.x`.

## 2. Старт и первые секунды

- Правило:
  - Оба стартуют с **x = 0**. Сущности карты `unit_player`/`unit_opponent` используются только как модели,
    их позиции каждый тик перезаписываются.
  - Скайрат: высота `(60+710)/2 = 385`, скорость 340.
  - Бэтрайдер: высота 0 → прижат к земле (60), скорость 320. Взмахивает, только когда впереди есть нижний
    камень (п. 3). До первого камня бежит по земле, ограничения `flLandedMaxSpeed` у него нет.
  - Скайрату падение смягчается первые 2 с: если вертикальная скорость < 0, она каждый кадр
    умножается на `min(1, t/2)` (t — время с начала забега). Автовзмахов нет.
- Константы: x=0; 385; 60; 2 с.
- Доказательство: `FUN_182925b50`, `FUN_18293d690`:
  ```c
  memset(&state, 0);                       // x of both = 0
  player.speed = diff->player.flInitialSpeed; player.vy = 0; player.y = (bounds.y + bounds.x) * 0.5;
  bat.speed = diff->opponent.flInitialSpeed; clampToBounds(bat);   // y 0 -> 60
  if (vel.y < 0) vel.y *= min(1.0, runTime * 0.5);
  ```
- Уверенность: высокая.
- Сейчас в порте: `opponentLead: 960`, `introTime: 1.2` с автовзмахами (logic.mjs:60–64, 192), старт на
  высотах 420/300 (logic.mjs:100–101).
- Что поменять: оба с x=0, Бэтрайдер на земле (60), Скайрат на 385; убрать автовзмахи; добавить множитель
  `min(1, t/2)` к скорости падения.

## 3. ИИ Бэтрайдера

- Правило:
  - Ищет **ближайший впереди нижний** камень (активный, `x > bat.x`). Если высота меньше
    `остриё + flBaseObstacleGapDistance/3` (= остриё + 150), взмахивает: `vy = flJumpPower` (600).
    Повтор не раньше `flActionCooldown` (0,075 с).
  - Верхние камни не учитывает. Столкновений у него **нет вообще**.
  - Скорость `+= 40·dt`, предел [50, 449]. К ней добавляется волна **`100·sin(t)`** (t — время забега в
    секундах, период ≈6,3 с): `x += (v + 100·sin t)·dt`. Отсюда обгоны туда-сюда: смещение до
    `±200` (`100·(1−cos t)`).
  - Земля: высота не ниже 60 (vy=0), не выше 710.
  - Финиш: x не больше `raceDistance + 200`. Если он за финишем и впереди Скайрата больше чем на 2000 —
    поражение сразу (реплика Бэтрайдера; в бесконечном — `skywrath.vo_failure`). Скайрату ставится
    «удар» на 99 с — управления больше нет.
  - **Дразнилок по ходу гонки нет**: из реплик в коде только `skywrath.vo_startrace` на старте,
    `skywrath.vo_victory` / `batrider.vo_victory` на финише гонки и `skywrath.vo_failure` в бесконечном
    режиме.
- Константы: 150 (=450/3); 0,075; 40; 449; 100·sin t; +200; 2000.
- Доказательство: `FUN_18293a5f0`:
  ```c
  if (flapCd <= 0) { o = nearest(!o->isTop && o->active && o->x > bat.x);
    if (o && bat.y < o->base + o->pos + diff->flBaseObstacleGapDistance / 3.0) { bat.vy = flJumpPower; flapCd = 0.075; } }
  vel += (accel, grav) * dt;  vel.x = clamp(vel.x, 50, 449);
  bat.x += (vel.x + sinf(runTime) * 100.0) * dt;  bat.y += vel.y * dt;
  if (raceDist < bat.x) { if (player.x + 2000.0 < bat.x && state != 3) lose(); bat.x = min(bat.x, raceDist + 200.0); }
  ```
- Уверенность: высокая.
- Сейчас в порте: `pilot` (logic.mjs:178–184) держит середину проёма в пределах 160–640. Бэтрайдер без
  синусоиды. Дразнилки раз в 9–15 с (logic.mjs:231–232).
- Что поменять: правило «остриё нижнего + 150» с кулдауном 0,075; синусоида `100·sin(t)`; убрать дразнилки
  (оставить только реплики старта и финиша).

## 4. Препятствия: когда, где, проём

- Правило:
  - Новая пара ставится, когда `созданных < int(cam.x / 450)` (одна за раз), в
    `x = cam.x + 1600 + RandomFloat(0, 85)`. Первая — когда камера дошла до 450, то есть около x≈2050–2135.
    В гонке — только пока `cam.x + 1600 < raceDistance − 250`.
  - Проём (между остриями) в **гонке — постоянный 450** (`flBaseObstacleGapDistance`).
    В бесконечном — `450 − 150·(t/180)` (t — секунды с начала забега), **без нижнего предела**: 300 на
    3-й минуте, 250 на 4-й…
  - Высота: `остриё_низ = RandomFloat(−70, 840 − проём)`, `остриё_верх = остриё_низ + проём`. Каждая пара
    независима — **ограничения сдвига между соседними проёмами нет**.
  - Убираются, когда `x < cam.x − 1600`.
- Константы: 450; 1600; 85; 250; 150/180 с; −70…840.
- Доказательство: `FUN_18293a390`, `FUN_1828f98b0`:
  ```c
  if (spawned < (int)(cam / diff->interval)) addObstacle();
  x0 = def->obstH.y + cam;  if (!endless && raceDist - 250.0 <= x0) return;
  gap = diff->baseGap;  if (endless) gap -= (gap - diff->minGap) * (stateTime / 180.0);
  low = RandomFloat(def->obstV.x, def->obstV.y - gap);  bottom.tip = low;  top.tip = low + gap;
  x = RandomFloat(0, 85.0) + x0;
  ```
- Уверенность: высокая.
- Сейчас в порте: `gapAt` (logic.mjs:74–77) — 450 → 300 по дистанции гонки. `makeObstacle` (81–91) —
  сдвиг соседних проёмов ≤ 200 (`maxGapShift`). `spawn` (112–121) — ровно каждые 450 от x=2000, до
  `finish − 450`.
- Что поменять: гонка — проём 450 всегда; бесконечный — по формуле от времени; убрать `maxGapShift`;
  шаг по камере 450 с разбросом +0…85; конец расстановки у `raceDistance − 250 − 1600` по камере.

## 5. Столкновения и удар

- Правило:
  - Скайрат — квадрат 100×100 (половина 50). Камень — отрезок шириной 100 у острия. Проверка:
    `|player.x − камень.x| < 50` (ширина Скайрата по x **не учитывается**). Нижний: `y − 50 < остриё`.
    Верхний: `y + 50 > остриё`.
  - Тот же камень (последний ударивший) повторно не бьёт; верхний и нижний — разные камни.
  - Пока идёт удар (0,5 с), проверок нет.
  - Удар в гонке: звук и частица, `vo_hurt`, `vy = 0`, скорость `−= 200` (затем не ниже 50).
    **0,5 с без гравитации, ускорения и взмахов** — висит на месте по высоте.
  - Удар в бесконечном — конец забега.
  - Потолок (710) не ранит: высота просто ограничивается, vy не обнуляется.
  - Земля (60): высота 60, vy=0, скорость `min(скорость, 200)`. Песок — звук и пыль раз в
    `RandomFloat(0,25; 0,5)` с. В бесконечном — конец забега.
- Константы: 50; 100; 200; 0,5; 60/710; 200; 0,25–0,5 с.
- Доказательство: `FUN_1828fb380`, `FUN_18293d690`:
  ```c
  half = vPlayerSize * 0.5;
  if (o->active && o != lastHit && fabs(p.x - o->x) < o->width * 0.5) {        // width = 100
    if (!o->isTop) hit = p.y - half.y < o->base + o->pos;  else hit = o->base + o->pos < p.y + half.y; }
  if (hit) { if (endless) { setState(3); return; } p.vy = 0; p.speed -= diff->flCollisionSpeedReduction;
             lastHit = o; hurt = diff->flCollisionInputCooldown; }
  ```
- Уверенность: высокая.
- Сейчас в порте: `touches` (logic.mjs:136–146) — контуры моделей из `scene.json` и бокс с шириной.
  Во время удара гравитация действует, `vz*0.5` (logic.mjs:216). Песок раз в 0,9 с (logic.mjs:222).
- Что поменять: простая проверка выше (можно оставить контуры для картинки, но столкновение — по
  остриям); при ударе vy=0, гравитация и ускорение выключены на 0,5 с; песок 0,25–0,5 с.

## 6. Финиш, счёт и время

- Правило:
  - Гонка: когда Скайрат пересекает `raceDistance`, x = raceDistance. **Победа, если Бэтрайдер ещё не за
    линией** (`bat.x < raceDistance`). Если Бэтрайдер финишировал раньше, победы нет: поражение сразу при
    отставании > 2000 или при пересечении линии. После финиша управления нет (удар на 99 с), состояние 3
    длится 1 с (бесконечный — 2,2 с), затем итог. Через 2 с после «AnimateOut» победа записывает в
    таблицу счёт **1 000** (первая награда).
  - Бесконечный: счёт `int(x / 2.5)` (0,4 за единицу), рекорд обновляется сразу.
  - Таймера гонки в коде нет.
  - Камера:
    - если Скайрат отстал от камеры больше чем на 350, камера встаёт на `x + 350` и берёт его скорость;
    - если он впереди камеры, камера встаёт на `x`;
    - между этими границами скорость камеры растёт на `remap(отн, −350..0 → 0..1)·300·dt`;
    - камера двигается, пока она перед финишем (в бесконечном всегда);
    - после конца — плавно `cam += (x − cam)·0,06` за кадр.
- Константы: 2,5; 1 000; 1 с / 2,2 с; 350; 300; 0,06.
- Доказательство: `FUN_18293d690`, `FUN_182931940`, `FUN_18290ab80`:
  ```c
  if (!endless && diff->raceDist < p.x) { p.x = diff->raceDist; won = bat.x < p.x; setState(3); }
  if (endless) score = (int)(p.x / 2.5);
  if (won) { leaderboardScore = 1000; best = max(best, 1000); }
  ```
- Уверенность: высокая.
- Сейчас в порте: финиш Бэтрайдера сразу даёт поражение (logic.mjs:233). Счёт `floor(max(0,x)·0.4)`
  совпадает. Камера — своя схема (logic.mjs:198–203).
- Что поменять: результат определять в момент финиша Скайрата (или поражение при отставании > 2000 за
  финишем Бэтрайдера); победа = 1 000 в рекорд; камера по правилу выше (необязательно).

- Доказательство: `FUN_1829387b0`:

  ```c
  if (pressed != wasPressed && pressed) if (hurt <= 0) { player.vy = def->flJumpPower; play("…flap"); }
  ```
- Уверенность: высокая.
- Сейчас в порте: `flap` (logic.mjs:150–157) — так же.
- Что поменять: ничего.

## Не найдено / не проверено

- Звук `crownfall.flappy.skywrath.boost` (Force Staff) в client.dll не упоминается: если он играет, то из
  Panorama (XML/JS), не из кода. Когда — не установлено.
- Почему Valve симулирует Бэтрайдера в бесконечном режиме — видимо, наследие гонки. Его правило «>2000
  впереди за финишем» там срабатывает, только если пользователь у 20 000 отстаёт больше чем на 1 800 —
  практически никогда.
- Отображение (поворот кольца каньона, частицы, анимации героя `run_injured`/`sky_arc_overkilled`/
  `generic_channel`/`defeat_fishing`) не разбиралось.

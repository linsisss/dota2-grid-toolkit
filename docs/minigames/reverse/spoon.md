## 1. Раскладка поля

- Правило:

    Ещё блоки ставятся принудительно в (2,0) и (0,2), если там пол.
  - Хранилище (`этап % 3 == 0`): столбец x=9. Выход (7) в (9,0), замки в (9,1…3), цвет `(y−1)%3`

## 4. Состав врагов этапа

- Правило (`FUN_1830037c0`), n = 5 на каждом 7-м этапе, иначе 3:
  - Группа A: n врагов. Таран, если этап чётный или кратен 7, иначе крип. Не-таран с этапа ≥2
    получает «закладывает бомбы» (`+0x31`). На 7-х этапах все — золотые (`+0x38`) с бомбами и
    пинком (`+0x31`, `+0x3a`).
  - Только этап 2: +1 крип-подрывник.
  - Этапы ≥3: группа B — n таранов. Один случайный из них золотой (с бомбами и пинком) при
    этапе > 3. На 7-х этапах все золотые.

  | Этап | Состав |
  |---|---|
  | 1 | 3 крипа |
  | 2 | 3 тарана + 1 крип-подрывник |
  | 3, 5, 9, 11… (нечётные, не 7k) | 3 крипа-подрывника + 2 тарана + 1 золотой (на 3-м — 3 тарана, без золотого) |
  | 4, 6, 8… (чётные, не 7k) | 5 таранов + 1 золотой |
  | 7, 14, 21… | 10 золотых |

- Появление: клетки пола вне квадрата 3×3 вокруг Спуна, с хотя бы одним проходимым соседом. Они
  перемешиваются и делятся на четверти поля (граница x < 9, y < 5). Враги ставятся по кругу:
  правый верх → правый низ → левый низ → левый верх.
- Константы: 3/5 на группу; максимум 16 врагов (16 слотов).
- Доказательство:
  ```c
  if (stage % 7 == 0) { *(char*)(g+0x8a66) = 0; n = 5; } else n = 3;
  e->charger = ((stage & 1) == 0) || stage % 7 == 0;
  if (!e->charger && 1 < stage) e->bombs = 1;            // +0x31
  if (stage % 7 == 0) { e->elite = 1; e->kick = 1; }     // +0x38, +0x3a
  ...
  if ((i == RandomInt(0,n-1) && 3 < stage) || stage % 7 == 0) { elite = bombs = kick = 1; }
  ```
- Уверенность: высокая.
- Сейчас в порте: `stageEnemies` (logic.mjs:65–73) — растёт до 9 врагов и 3 золотых, на 7-х 12 золотых;
  крипы не закладывают бомбы, золотые не пинают.
- Что поменять: таблица выше (с 3-го этапа всегда 6, на 7k — 10); места по четвертям.

## 5. ИИ врагов (`CCreep::Update`)

- Правило:
  - Скорость ходьбы у всех **1,5 кл/с**, рывок тарана **4,5 кл/с**. Золотой не быстрее.
  - Обычная ходьба: прямо, пока не упрётся. Тогда случайное направление из всех открытых, кроме текущего
    (разворот назад тоже возможен), и **пауза 0,25 с** (состояние 5). На перекрёстках обычный враг не
    сворачивает. Проходимы пол (0), лежащие предметы и выход (5, кроме замков) и сгорающие предметы (6).
    Бомба (4) и блоки — стена.
  - Таран (`+0x30`): в центре клетки с шансом **1/20** делает рывок сам. Иначе — если Спун в той же
    строке или столбце **впереди по ходу** на любом расстоянии и путь свободен. Рывок до стены, затем
    «бонк» **1,0 с**, звук `WallHit`.
  - Золотой (`+0x38`) в центре клетки:
    - если видит Спуна по прямой в любую сторону (огонь закрывает обзор), разворачивается к нему;
    - затем выбирает поворот среди других открытых направлений без бомбы или огня в конце коридора;
      сворачивает всегда, если бомба или огонь ≤ 2 клеток впереди, иначе с шансом 1/4;

    только с шансом 1/3.

## 6. Спун: скорость, бомбы, улучшения

- Правило:
  - Скорость — `2.5 + 0.75·уровень` кл/с, уровень 0…8. База 2,5 — значение в коде (`charWalkSpeedBase`
    в CSS нет), прирост 0,75 — из `@define`. За кадр не больше 0,495 клетки. Во время неуязвимости после
    возрождения уровень не ниже 3.
  - Бомбы: старт 1, максимум **9**.
  - «Дальность» хранится как размер 3 + 2·n, максимум 19; HUD показывает `(размер−1)/2`, то есть 1…9.
    Луч обычной бомбы — `размер/2` клеток (1…9). Луч шипастой — **`размер` клеток** (3…19, вдвое длиннее
    плюс 1) и проходит сквозь блоки.
  - Пинок, шипы и пульт **взаимоисключающие**: при подборе одного другой выпадает и улетает на случайную
    свободную клетку.
  - Бомба ставится только на пол (не на лежащий предмет). Если кнопку держать, бомба ставится, как только
    станет можно. Общий пул бомб — 12 на всех, включая врагов.
  - Пульт: Alt взрывает **все** свои бомбы на пульте сразу. Пульт также останавливает последнюю пнутую
    бомбу (если прошла > 0,5 клетки — она докатывается на клетку).
  - Пинок действует на любую бомбу рядом (и вражескую), кроме только что поставленной под собой. Бомба
    катится только по пустому полу (не на предметы, врагов, Спуна) со скоростью 5 кл/с.
- Константы: 2,5; 0,75; 0,495; 9; 3+2n ≤ 19; 8 уровней скорости; 12 бомб.
- Доказательство: `FUN_1830140f0`, `FUN_183007aa0`, `FUN_182ffd1d0`, `FUN_182ffab90`:
  ```c
  lvl = speed; if (invuln > 0 && respawned && lvl < 3) lvl = 3;
  step = min((lvl * walkInc + walkBase) * dt, 0.495);          // base +0xa4 = 2.5, inc +0xa8
  case 0: bombs = min(bombs + 1, 9);  case 1: size = min(size + 2, 19);  case 2: speed = min(speed + 1, 8);
  case 3: kick = 1; if (spiky) { spiky = 0; eject(5); } if (remote) { remote = 0; eject(6); }
  range = bomb->size / (2 - (bomb->spiky != 0));               // neg al; sbb; add 2; idiv
  ```
- Уверенность: высокая.
- Сейчас в порте: `walkSpeedBase: 2.75` (logic.mjs:33), `maxBombs 8, maxSize 8, maxSpeed 6`
  (logic.mjs:37), пинок совместим с шипами/пультом (logic.mjs:408–410), шипастая бомба той же длины
  (logic.mjs:491), Alt взрывает одну старшую бомбу (logic.mjs:387).
- Что поменять: база 2,5, предел скорости 8 уровней (HUD 9), бомб 9, дальности 9; шипы — длина `2·range+1`;
  три спецспособности взаимоисключающие с выбросом старой; Alt взрывает все бомбы на пульте.

- Правило:
  - Фитиль 3 с (`bombDuration`), огонь 0,45 с. Бомба взрывается, если её клетка горит.
  - Луч от центра в 4 стороны на `range` клеток:
    - пол и **бомбы — огонь идёт дальше** (бомба поджигается и взорвётся в следующем тике);
    - ломаемый блок начинает ломаться (0,45 с); обычный луч на нём останавливается, клетка блока не горит;
      шипастый проходит;
    - колонна, ломающийся блок и замок останавливают огонь;
    - лежащее улучшение или ключ **не сгорает**: улетает (0,5 с) на случайную клетку пола, и луч
      останавливается. Улучшение сгорает, только если свободного пола нет. Ключ не сгорает никогда;
    - открытый выход останавливает луч. Огонь по нему выпускает **нового крипа** в клетке выхода
      (не чаще раза в 2 с, 1 с неуязвим, стоит 10 очков).
  - Летящий предмет, приземлившийся в огонь, выбирает новую клетку.
  - Спун гибнет в горящей клетке (своей, если нет неуязвимости).
  - Бомбы врагов: дальность 1 у крипа, 2 у золотого и бомбардировщика; фитиль тот же 3 с.
- Константы: 3; 0,45; 0,5 (полёт предмета); 2 с и 1 с (крип из выхода).
- Доказательство: `FUN_182ffd1d0`, `FUN_183010360`, `FUN_183011410`:

- Сейчас в порте: `detonate` (logic.mjs:480–517) — огонь останавливается на бомбе (503), улучшение
  сгорает (505), ключи не горят; крипов из выхода нет.

  открытому выходу выпускает крипа (кулдаун 2 с, 10 очков).

## 8. Очки

- Правило:
  - Враг: 100, золотой — 500, крип из выхода — 10, умножается на текущий множитель. Множитель
    1 → 2 → 4 (предел 4). Он **общий**, держится **0,45 с** после последнего убийства, потом сбрасывается
    в 1. Не привязан к взрыву или его цепи. Любой огонь даёт очки.
  - Улучшения и ключи — **0 очков**.
  - Выход: после 0,5 с каждые 0,025 с −2 секунды таймера и +10 очков (то есть 5 за секунду, 80 с/с).
    Подсчёт идёт параллельно с анимацией выхода (2 с).
  - Время вышло: враги убираются без очков (п. 10).
  - Других источников очков нет: все записи в `game+0x741c` — только эти три места и сброс.
- Константы: 100/500/10; ×1, ×2, ×4; 0,45 с; 10 за 2 с.
- Доказательство: `FUN_183007ff0` (+ сброс в `FUN_183011710`):
  ```c
  pts = elite ? 500 : 100;  g->chainTimer = 0.45;  if (fromExit) pts = 10;
  mult = g->mult;  g->mult = min(mult * 2, 4);  g->score += mult * pts;
  // tick: if (g->chainTimer <= 0) g->mult = 1; else g->chainTimer -= dt;
  ```
- Уверенность: высокая.
- Сейчас в порте: `SCORE` (logic.mjs:21) с `pickup: 10`, множитель по группе взрыва (`killEnemy`,
  logic.mjs:533–543), тайминг подсчёта — после анимации (logic.mjs:236–251).
- Что поменять: убрать 10 за подбор; множитель — глобальный с окном 0,45 с; очки за убийства любым огнём.

## 9. Бомбардировщики (`CDropper`)

- Правило:
  - Волна по таймеру (п. 3). Цели — случайные клетки пола по всему полю, без исключений рядом со Спуном.
    Первый бомбардировщик стартует сразу, остальные — по одному каждые **0,25 с**. Следующий интервал
    отсчитывается после выпуска последнего.
  - Каждый летит из-за края с случайной стороны (направление 0…3) **вдоль строки или столбца своей
    цели** на 7 кл/с. Над целью висит 0,25 с и бросает бомбу дальности 2 (ничья, фитиль 3 с). Если цель
    уже не пол и не бомба — ничего не бросает. Если там бомба — новая бомба взрывается сразу. Улетает на
    9 кл/с.
  - Неуязвим. Звук `DropperEnter` на каждого.
- Константы: 3/5 штук, 8/5 с, 0,25 с между вылетами, 7 и 9 кл/с, висение 0,25 с, размер 5.
- Доказательство: `FUN_183011130`, `FUN_1830147e0`:
  ```c
  speed = (state == 3) ? 9.0 : 7.0;
  if (state == 1 && atTarget) state = ((cell & ~4) == 0) ? 2 : 3;
  else if (state == 2 && 0.25 <= t) { state = 3; if ((cell & ~4) == 0) { place(x,y,5); if (was == 4) explode(); } }
  ```
- Уверенность: высокая.
- Сейчас в порте: `updateDroppers`/`launchDropper` (logic.mjs:623–668): 1–3 штуки раз в 14–22 с, 3 кл/с,
  1–2 цели на ряд, фитиль 2 с.
- Что поменять: по правилу выше.

## 10. Жизни, смерть, время вышло

- Правило:
  - 2 запасные жизни, **дополнительных жизней нет** (жизни только уменьшаются).
  - Смерть длится 3 с (`deathDuration`). Все улучшения разлетаются (0,5 с) на случайные клетки пола вне
    квадрата 3×3 вокруг Спуна: бомбы до 1, дальность до 1, скорость до 0, спецспособность, ключ.
  - Возрождение **на том же месте** (позиция не сбрасывается) с неуязвимостью **6 с** и скоростью не ниже
    3-го уровня, пока она длится. Звук `FallIn`.
  - Время вышло (`elapsed ≥ limit + 0,1`): Спун погибает, **все враги убираются без очков**, таймер
    ставится на **60 с**.
  - При 0 жизнях после смерти — «Игра окончена» 3 с, затем меню.
- Константы: 2; 3 с; 6 с; уровень 3; 60 с; 3 с.
- Доказательство: `FUN_183011710`, `FUN_183014b10`:
  ```c
  if (lives < 1) { state = 4; } else { pstate = 0; lives--; invuln = 6.0; respawned = 1; } // pos untouched
  if (limit + 0.1 <= elapsed && state == 0) { killPlayer(); for (e : enemies) e->Kill(g, 0);
      elapsed = limit - 60.0; }
  ```

- Уверенность: высокая.
- Сейчас в порте: `respawn` (logic.mjs:445–451) — в угол (0,0), неуязвимость 2 с, таймер заново на полное
  время; враги после «время вышло» остаются.
- Что поменять: возрождение на месте, 6 с, ускорение до 3-го уровня, таймер 60 с и уборка врагов без
  очков.

## 11. Выход, замки, ключи

- Правило:
  - Выход срабатывает, только если **врагов не осталось** — и на обычном этапе, и в хранилище. В хранилище
    нужны и открытые замки, и убитые враги. Крипы из выхода тоже считаются.
  - Ключ: держится один. При подборе другого старый улетает на случайную свободную клетку пола (если
    её нет — остаётся на месте, меняется местами).
  - Замок открывается, если упереться в него с ключом цвета `замок−3`. Замок ломается как блок, звук
    `Unlock`.
  - Когда враги кончились, а выход уже открыт, один раз звучит `Unlock`.
- Доказательство: `FUN_183007aa0`:
  ```c
  case 6: if (0 < g->enemyCount) return 0;   /* exit */  ...
  case 10..12: if (held == content - 3) { held = 0; cell.type = 3; snd |= 0x800; }
  ```
- Уверенность: высокая.
- Сейчас в порте: выход в хранилище открывается от замков без проверки врагов (logic.mjs:277); старый ключ
  кладётся на ту же клетку (logic.mjs:403).
- Что поменять: условие выхода — 0 врагов везде (плюс замки); старый ключ улетает на случайную клетку.

# «Сапёр Сплин» (sweeper, Valve: minesweeper) — разбор client.dll

Бинарник: client.dll 107 533 976 байт, SHA-256 dfec84e4…ceefd6, депо 373303, манифест 5121451448605799518
(2026-10-15).

Где логика: доска — класс без RTTI-имени в 0x182bc1000–0x182bcf000 (ячейка: `+0x8` мина, `+0xc` число,
`+0x10` открыта, `+0x11` флаг, `+0x13` «ещё не разыгрывалась под предмет», `+0x14` кликов у Clarity, `+0x18`
кликов у часов; доска: `+0x20` жизни, `+0x24` мана, `+0x28` мины, `+0x2c` «первый клик», `+0x30` пересборок).
Попап `CDOTA_DB_Popup_BP_Crownfall_Encounter_Minesweeper`: ЛКМ `FUN_182907190`, ПКМ `FUN_182906f30`, неудачный
аккорд `FUN_18291fef0`. Доступ к vdata идёт через указатель со сдвигом +8 (`+0x738` = `m_nManaPotRestoration`
0x730 и т. д.).

## 1. Генерация поля и первый клик

- Правило. Мины ставятся при создании этапа равномерно по всему полю (`RandomInt` строки и столбца, повтор при
  занятой) — до клика. Первый ЛКМ (флаг `+0x2c`) принимается, только если клетка без мины, с числом 0, открытая
  область ≥ 10 % поля (convar `dota_minesweeper_minimum_board_open_threshold` = 0.1) **и область не
  прямоугольник** (в каждой строке с открытыми клетками одинаковые число и первый столбец → отказ). Иначе поле
  пересобирается целиком и клик повторяется; после 20 пересборок (`dota_minesweeper_max_board_setup_retries`)
  принимается любая клетка без мины с нулём (мина/число всегда ведут к пересборке).
- Echo Slash первым действием этой защиты не получает (`FUN_182bc5d00(..., param_7 = 0)`).
- Доказательство: `FUN_182bca7c0` (мины), `FUN_182bc5d00`:
  ```c
  if ((!mine) && (adj < 1)) {
    if (*(int *)(_DAT_18640ad50 + 0x58) <= retries) goto accept;           /* 20 */
    if (cvar_open_threshold <= (float)opened / (float)(rows * cols)) { /* проверка «не прямоугольник» */ }
  }
  FUN_182bca7c0(param_1, *param_1); retries++; ... FUN_182bc5d00(param_1, r, c, ...);   /* пересборка */
  ```
- Уверенность: высокая.
- Сейчас в порте: `placeMines` — мины по клику, без мин в 3×3 вокруг него.
- Что поменять: генерировать до клика и пересобирать по правилу выше (ноль + ≥10 % + не прямоугольник, до
  20 раз); для Echo Slash первым действием — без пересборки.

## 2. Появление предметов

- Правило. После каждого ЛКМ-действия для каждой **только что открытой** клетки перебираются её 8 соседей.
  Сосед, который закрыт, без флага и ещё ни разу не разыгрывался (`+0x13`), разыгрывается один раз за всю
  игру этапа (флаг снимается):
  1) если Clarity на поле < `m_nMaxConcurrentManaPots` (5) и `RandomInt(1,100) ≤ m_nManaPotChance` (4) →
     Clarity с `m_nManaPotExpireClicks` (5) кликами;
  2) иначе, если часов < `m_nMaxConcurrentTimerIncreases` (3) и `RandomInt(1,100) ≤ m_nTimerIncreaseChance`
     (3) → часы с 5 кликами.
  Перебор кончается, когда достигнуты оба максимума. **На мину предмет класть можно** (проверки нет).
- Доказательство: `FUN_182bcd9b0`:
  ```c
  if (cell->eligible && !cell->revealed && !cell->flagged) { cell->eligible = 0;
    if (pots < def->maxPots && RandomInt(1,100) <= def->potChance) { cell->potClicks = def->potExpire; pots++; }
    else if (timers < def->maxTimers && RandomInt(1,100) <= def->timerChance) { cell->timerClicks = ...; } }
  ```
- Уверенность: высокая.
- Сейчас в порте: `afterAction` — каждая открытая клетка бросает шанс, предмет кладётся в случайную закрытую
  клетку рядом с открытыми (`itemSpot`).
- Что поменять: бросок по соседям каждой открытой клетки, не более одного броска на клетку за этап, предмет
  кладётся именно в этого соседа; порядок «сначала Clarity, иначе часы».

## 3. Счётчик кликов предметов

- Правило. Каждый вызов ЛКМ по доске (`FUN_182bc5c20`) и каждый Echo Slash сначала уменьшает счётчики **всех**
  предметов на 1 — даже если клик ничего не открыл (клик по флагу, неудачный аккорд); на 0 предмет исчезает
  («lost»). Потом появляются новые (с полными 5 кликами). ПКМ (флаги) не считается.
- Подбор: открыта клетка с предметом и это не мина → Clarity: мана += 25, не выше `m_nInitialMana`; часы:
  время += `m_flTimeExtension` (30). Предмет на мине пропадает вместе со взрывом.
- Доказательство: `FUN_182bc5c20` вызывает `FUN_182bcd9b0` безусловно; в нём
  `potClicks = max(potClicks − 1, 0)`, флаги 0x400/0x800 = «исчез».
- Уверенность: высокая.
- Сейчас в порте: «кликом» считаются только действия, которые что-то открыли.
- Что поменять: уменьшать счётчики на любой ЛКМ по полю и на Echo Slash.

## 4. Предмет под флагом («перескок»)

- Правило. Флаг (одиночный или аккорд ПКМ) снимает предмет с клетки; у предмета остаётся `клики − 1`
  (если стало 0 — пропадает). Новое место, по приоритету:
  1) случайный сосед флажков (8 клеток), закрытый, без флага и предмета, **касающийся открытой клетки**;
  2) любой такой сосед без открытых рядом;
  3) случайная клетка всего поля: закрытая, без флага и предмета, касающаяся открытой;
  4) иначе предмет пропадает. Мины допускаются. Клетка, получившая предмет, больше не разыгрывается.
- Доказательство: `FUN_182bc1f10` (+ лямбды `FUN_182ba6770`, `FUN_182ba7270`, `FUN_182ba7660`):
  ```c
  if (0 < potClicks - 1) moved[n++] = potClicks - 1;  ... *(undefined8 *)(cell + 0x14) = 0;
  if (preferred.count) pick(preferred) else if (neighbours.count) pick(neighbours) else pick(boardWide);
  ```
- Уверенность: высокая (средняя — порядок при нескольких предметах сразу).
- Сейчас в порте: `hopItems` — случайный закрытый сосед, иначе `itemSpot`; клики не уменьшаются.
- Что поменять: −1 клик при перескоке, приоритет «сосед у открытой → сосед → любая клетка у открытой».

## 5. Аккорды и «Отдых»

- Правило. Неудача = ЛКМ или ПКМ по открытой клетке с числом, после которого ничего не изменилось, при нулевой
  перезарядке. Счётчик +1; при `≥ m_nFailedChordClickTimes` (6): счётчик −= 6, перезарядка += 5 с.
  Счётчик обнуляется, когда ЛКМ что-то открыл (в том числе обычный клик по закрытой клетке); ПКМ его не
  обнуляет. **Во время перезарядки блокируются только аккорды** (в `FUN_182bc5c20`/`FUN_182bcd280`
  передаётся `cooldown <= 0.001` как «аккорды разрешены»), открывать клетки и ставить флаги можно.
- Доказательство: `FUN_18291fef0`:
  ```c
  *(int *)(param_1 + 0x250) += 1;
  if (def->failTimes <= fails) { fails -= def->failTimes; *(float *)(param_1 + 0x254) += (float)def->cooldown; }
  ```
- Уверенность: высокая.
- Сейчас в порте: `canPlay` запрещает любые клики во время «Отдыха»; удачный аккорд ПКМ обнуляет счётчик.
- Что поменять: в перезарядке отклонять только аккорды (клики по числам), ПКМ-аккорд не обнуляет счётчик;
  при срабатывании вычитать 6, а не обнулять.

## 6. Echo Slash

- Правило. Только по закрытой клетке без флага, мана ≥ `m_nIllusionManaCost` (50). Мана −50. Мина: мин −1,
  числа соседей пересчитываются, клетка открывается как обычная (если стала нулём — открывается и область
  вокруг). Безопасная — обычное открытие с заливкой. Затем счётчик кликов предметов (п. 3).
- Доказательство: `FUN_182bce420`. Уверенность: высокая.
- Сейчас в порте: мина-клетка открывается без заливки.
- Что поменять: после снятия мины открывать клетку через `flood` (если число стало 0 — с областью).

## 7. Прочее (совпадает)

Очки (15 за клетку, 4000 за этап, 20 за секунду), +15 с за этап, 1 жизнь, мана 250 — как в vdata; конец этапа
по `открыто == строки × столбцы − мины` (`FUN_182bc5d00`).

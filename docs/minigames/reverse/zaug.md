## 1. Состояния Зауга и их длительности

- Правило. Босс — конечный автомат с очередью `(состояние, длительность)`. Когда текущее состояние кончилось
  (`tick ≥ +0x240`) и очередь пуста, ИИ кладёт в неё следующую серию (§2). Длительность 0 → берётся из vdata:

  | № | Состояние | Длительность | Куда летит (x, y) @ скорость ед/с |
  |---|---|---|---|
  | 1 | Intro | `m_flIntroDuration` 3 | (1000, 300) @ 900; появляется в (2400, 300) |
  | 2 | Idle | задаётся явно: 0,5 / 0,9 / 1 / 1,5 | (1000, 300) @ 100 |
  | 3 | MouthLaser_Charging | `m_flMouthLaserChargeTime` 0,35 | (1000, 450) @ 800 |
  | 4 | MouthLaser_Blasting | `m_flMouthLaserDuration` 2 | цель не меняется (остаётся (1000, 450)) @ 500 |
  | 7 | Blasting, вариант 7 | 2 | (1400, 400) @ 500 |
  | 8 | Blasting, вариант 8 | 2 | (1400, 600) @ 500 |
  | 9 | WingBarrage_Tell | `m_flWingBarrageChargeTime` 0,7 | (900, 290) @ 500 |
  | 10 | WingBarrage | `m_flWingBarrageDuration` 3,4 | (900, 290) @ 500 |
  | 11 | ColdEmbrace | `m_flColdEmbraceDuration` 5 | (1100, 400) @ 300 |
  | 12 | SplinterBlast_Tell | `m_fSplinterBlastChargeTime` 0,5 | (1000, 300) @ 500 |
  | 13 | SplinterBlast | `m_flSplinterBlastDuration` 1 | (1000, 300) @ 500 |
  | 15 | смена цвета босса | 0 (1 тик) | — (скорость 500) |
  | 16 | BlanketCover | 4,25 (константа) | (1100, 320) @ 500 |
  | 17 | Flee | 5 (константа) | (400, −800), скорость = расстояние / 5 с |
  | 18 | Escaped | 120 | конец игры (поражение) |

  Состояния 5 и 6 (лазер из (1000, 150) и (1000, 550), узоры 3 и 2) в коде есть, но в очередь никогда не
  попадают; узоры 2, 3, 11, 14 не используются. `m_vIdlePosition` не используется: все позиции
  захардкожены.
- Движение: каждый тик `pos += normalize(target − pos) · min(|target − pos|, speed/60)`; на входе в любое
  состояние скорость сбрасывается в 500, затем переопределяется по таблице.
- Неуязвимость (`enemy+0x25`): сбрасывается на входе в каждое состояние, ставится только в Intro и ColdEmbrace.
  Попадание в неуязвимого — звук `crownfall.shmup.enemy.armor`, ни урона, ни очков урона.
- Доказательство: `FUN_182cebe80` (длительности), `FUN_182ce9280` (позиции):
  ```c
  case 3: param_3 = *(float *)(def + 0x8c); break;      /* m_flMouthLaserChargeTime */
  case 0x10: param_3 = 4.25; break;  case 0x11: param_3 = 5.0; break;  case 0x12: param_3 = 120.0;
  ...
  case 3: /* k_eBossState_MouthLaser_Charging */ +0x260 = 1000.0; +0x264 = 450.0; +0x278 = 800.0;
  case 0xb: /* ColdEmbrace */ enemy+0x25 = 1; +0x260 = 1100.0; +0x264 = 400.0; +0x278 = 300.0; +0x210 = 2;
  ```
- Уверенность: высокая.
- Сейчас в порте: `bossAttack`/`stepBoss` (стр. 415, 480): своя очередь laser→wing→splinter→breath, «восьмёрка»
  вокруг `BOSS_IDLE`, случайная новая высота после атаки.
- Что поменять: завести очередь состояний с этой таблицей и движением «к точке с ограничением скорости»;
  убрать дрейф и случайные высоты; состояния «breath» нет.

## 2. Порядок атак и фазы (CShmupBossPhase не используется: порядок — код)

- Правило (`FUN_182cfd740`, проверяется только в момент конца состояния):
  1. Если `tick ≥ конец боя` и ещё не убегал: очистить очередь → Flee, Escaped.
  2. Иначе если фаза < 2 и `HP < maxHP / 2` (целочисленно, т. е. HP ≤ 499): очистить очередь →
     **ColdEmbrace, Idle 1,5, SplinterTell, SplinterBlast, Idle 1** (один раз за бой).
  3. Иначе, если очередь пуста, по последнему состоянию:
     - после Intro: Idle 0,5, WingTell, Wing, Wing, смена цвета, Idle 0,9, Charge, Laser4;
     - фаза 1 (HP ≥ 50 %), каждый цикл: смена цвета, WingTell, Wing, Wing, смена цвета, Idle 0,9, Charge,
       Laser4; с вероятностью 30 % ещё: смена цвета, Idle 0,5, Charge, Laser4;
     - фаза 2 (после Cold Embrace), чередование A/B:
       - A (если живых осколков нет и прошлый раз был не A): SplinterTell, SplinterBlast, Idle 1, затем два
         лазера 7 и 8 в случайном порядке (50/50), каждый с Charge перед ним и сменой цвета между ними
         (при порядке 7→8 смена цвета стоит и перед первым), Idle 0,5;
       - B: смена цвета, WingTell, BlanketCover, BlanketCover, Idle 1.
  Цвет босса при появлении — лёд (0); меняет его только состояние 15. Первая серия крыльев — синяя.
- Доказательство: `FUN_182cfd740`:
  ```c
  if (tick < fightEnd) { if (phase < 2 && hp < maxHp / 2) { clear(); push(0xb,0); push(2,1.5f);
        push(0xc,0); push(0xd,0); push(2,1.0f); } }
  else if (!fled) { clear(); push(0x11,0); push(0x12,0); }
  ...                                   /* фаза 1 */
  push(0xf,0); push(9,0); push(10,0); push(10,0); push(0xf,0); push(2,0.9f); push(3,0); push(4,0);
  if (RandomFloat() < 0.3) { push(0xf,0); push(2,0.5f); push(3,0); push(4,0); }
  ```
- Уверенность: высокая.
- Сейчас в порте: `BOSS_CYCLE = ['laser','wing','splinter','breath']`, Cold Embrace на 2/3 и 1/3 HP
  (`stepBoss`, стр. 513).
- Что поменять: сделать ровно эти серии; Cold Embrace — один раз, при HP < 50 %; осколки и BlanketCover — только
  во второй фазе (и осколки сразу после Cold Embrace).

## 3. Что делает каждое состояние (узоры, точки прицела, источник)

- Правило. Атака — команда стрельбы на враге-боссе: номер узора из `m_vecBulletPatterns`, номер части тела,
  откуда летят пули (`m_vecBodyParts[i]`: 0 = `attach_head`, 3 = `attach_spine_2`), задержка, точка прицела.
  **Все атаки Зауга целятся в фиксированную точку у левого края, а не в Шен**:

  | Состояние | Узор | Источник | Задержка | Прицел |
  |---|---|---|---|---|
  | Laser4 | 1 | голова | 0,6 с | (0, 350) |
  | Laser7 / Laser8 | 4 | голова | 0,6 с | (0, 210) / (0, 525) |
  | WingBarrage (каждое из двух) | 0 | spine_2 | 0 | (0, 350) |
  | BlanketCover (каждое из двух) | 9+10 (нечётный счётчик входов в состояния) или 12+13 | spine_2 | 0,5 с | (0, 350) |
  | конец Cold Embrace (вход в следующее) | 6, 7, 8 сразу | spine_2 | 0 | кольца |
  | взрыв осколка | 5 | точка осколка | 0 | кольцо |

  Цвет пуль — цвет босса в момент входа (у 9/10/12/13 ещё и смена цвета на каждой пуле). Команды не
  прерываются сменой состояния: стреляют, пока не выпустят `m_nCount`.
- Доказательство: `FUN_182ce9280`:
  ```c
  if (st == 4) { cmd.pattern = 1; aimY = height * 0.5f; } ...  aimX = 0;
  cmd.delay = 0.6f; cmd.useAim = 1; cmd.color = boss->red;           /* лазер */
  case 10: cmd.pattern = 0; cmd.bodyPart = 3; ...                     /* крылья */
  case 0x10: base = (stateCounter & 1) ? 9 : 12; for (i<2) { cmd.pattern = base+i; cmd.bodyPart = 3;
            cmd.delay = 0.5f; aimX = 0; aimY = height*0.5f; }
  ```
- Уверенность: высокая (поля команды сопоставлены по потребителю `FUN_182ccb630`/`FUN_182cfab70`).
- Сейчас в порте: `bossFire` (стр. 426): лазер = 9+10/12+13 из пасти, крылья = узоры 2 и 3 четырьмя залпами,
  «дыхание» 0/1/4, прицел в Шен; конец Cold Embrace — узоры 5–8 с чередованием цвета.
- Что поменять: по таблице; узоры 2 и 3 не нужны; кольца в конце Cold Embrace — 6, 7, 8 цветом босса.

## 4. Cold Embrace

- Правило. 5 с, босс неуязвим, летит к (1100, 400) со скоростью 300, анимация замедляется
  (`rate = max(0, 0.8 − 0,003·тиков)`), через 0,6 с — звук `boss.coldembrace` и частица льда.
  На входе: рёв, **живые дракончики улетают вправо** (15 ед/тик, исчезают за `x > W + 40`, без очков);
  **новых дракончиков не зовёт и не лечится** — прибавления HP во всём коде босса нет. На выходе (вход в
  следующее состояние): `ice_shatter`, звук `coldembrace.shatter`, три кольца 6/7/8. Дальше Idle 1,5 и
  Splinter Blast.
- Доказательство: `FUN_182ce9280` (case 0xb, блок «если частица льда есть»), `FUN_182cfd740` (state 0xb).
- Уверенность: высокая для неуязвимости/колец/дракончиков; «лечения нет» — средняя-высокая (не найдено ни
  одной записи HP вверх; HP пишется только вычитанием в `FUN_182cc1350`/`FUN_182ccb840`).
- Сейчас в порте: лечит 20 HP/с, зовёт двух дракончиков, кольца 5–8 (`stepBoss` стр. 509, `bossFire` case
  'embrace').

## 7. Узоры пуль (`FUN_182cfab70`): ширина, синус, чередование, темп

- Правило (t — время с начала команды минус задержка; i — номер пули с 0):
  - **Темп:** при `m_flInterval > 0` выпущено `min(count, floor(t / interval) + 1)` пуль — **по одной пуле на
    интервал**, волны — только группировка углов. При `interval = 0` — все сразу. Пуля i рождается
    «задним числом»: её позиция сдвигается на `v · (t − i·interval)`.
  - **Radial:** угол `i·2π/count + i·m_flAngleOffsetPerBullet`, направление `(−cos a, sin a)` (пуля 0 — влево);
    скорость и радиус базовые; ни случайного поворота, ни `m_flAngleOffset`.
  - **HorizontalLeft:** (−1, 0), базовая скорость. HorizontalRight / VerticalInwards / VerticalOutwards — не
    стреляют вовсе (в данных не встречаются).
  - **FixedDirection:** `m_vFixedDirection`, скорость `speed + i·speedPerBullet`.
  - **Player:** каждая пуля целится в текущую позицию Шен + случайный сдвиг
    (`m_flRandomTargetingOffsetMin…Max`), угол `+ i·offsetPerBullet`; скорость и радиус базовые.
  - Прицел **PlayerSpreadRandom / PlayerSpreadEven**: точка, запомненная в момент команды (у врагов на путях —
    позиция Шен в момент события Shoot; с `m_bUseStoredPlayerLocation` — сохранённая StorePlayerPosition;
    у босса — точка из §3), направление от текущей позиции источника.
  - **PlayerSpreadRandom:** угол равномерно в `[aim − w·π, aim + w·π] + m_flAngleOffset`,
    `+ i·offsetPerBullet + (i div perWave)·offsetPerWave`; скорость `+ i·speedPer`, радиус `+ i·radiusPer`.
  - **PlayerSpreadEven:** `wave = i div perWave`, `j = i mod perWave`, `nW = count div perWave`:
    `a = aim − w·π + offset + j·(2w·π)/(perWave − 1) + i·offsetPerBullet + wave·offsetPerWave
       + (wave чётная ? m_flAngleStaggerPerWave : 0) + (nW > 0 ? sin(wave·π / nW)·m_flAngleSinWaveOffset : 0)`;
    скорость/радиус как у Random; `m_bSwapColorPerBullet` — нечётные i другого цвета.
  - Итого: **`m_flAngleWidth` — полуширина в долях π** (0,36 → ±65°), синус — **одна полуволна на весь узор**
    (0 → 1 → 0), чередование — на чётных волнах (начиная с 0-й).
- Доказательство: `FUN_182cfab70` (дизассемблер, ветка Even `0x182cfb110`):
  ```asm
  mulss xmm2,[rbx+0x1c] ; *π        ; halfW = width·π
  addss xmm8,[rbx+0x34]  (если wave чётная)   ; stagger
  mulss xmm0,π ; divss xmm0,nW ; call sinf ; mulss xmm0,[rbx+0x38]   ; sin(wave·π/nW)·sinOffset
  cvttss2si eax, t/interval ; inc eax ; cmovge esi,eax                 ; min(count, ⌊t/int⌋+1)
  ```
- Уверенность: высокая.
- Сейчас в порте: `emit` (стр. 284–323): целая волна за интервал, ширина в радианах (`±width/2`), синус
  `sin(w·2π/30)`, stagger на нечётных, у Radial случайный поворот + offset, прицел пересчитывается в Шен на каждом
  выпуске.
- Что поменять: всё по формулам выше. Это меняет всех врагов: у фамильяра веер ±27° вместо ±4°, Фэй Лянь —
  поток из 30 пуль за 3 с, проходящий веер ±36°, а не залп из 30.

## 8. Очки: урон, убийства, комбо, итоговые бонусы, рейтинг

- Урон (`FUN_182ccb840`): к категории Damage прибавляется **весь** урон попадания (с ×2 за чужой цвет), не
  урезанный остатком HP и до деления по регионам. Не считаются: столкновения телом (тип 7/8 — сердце Шен) и
  попадания в неуязвимого.
- Убийство: `m_nKillScore` в EnemyKill (кто бы ни убил).
- Комбо (`FUN_182ce6450`), **только пока Зауг не появился** (фаза 0): первая — цепочка 1; другой цвет посреди
  цепочки — «прервано» (уведомление и звук — только при комбо > 0), комбо 0, цепочка 1 нового цвета; третье
  подряд — бонус `m_nComboBaseScore << min(комбо, 9)` (100…51 200), комбо+1, цепочка 0. **При возрождении
  Шен комбо и цепочка обнуляются молча** (`FUN_182cfffd0`, переход dead→respawning).

## 9. Попадания по Заугу: регионы тела

- Правило. Части тела копируют из vdata только радиус и `m_nHitRegionIndex`; **`m_nDamageMultiplier` не
  читается**. Регион 0 (голова и шея) — полный урон; регионы 1–2 (позвонки, колени, хвост) —
  `max(1, урон div 2)`; ≥ 3 — без урона. Особая атака бьёт босса всегда как регион 0 (цель — часть 0, голова).
  Касание части тела Шен (если она умерла от этого) наносит боссу `m_nEnemyCollideDamage` 20 с регионом части.
- Доказательство: `FUN_182ccbf50` (`part+0x14 = radius; part+0x38 = m_nHitRegionIndex`), `FUN_182ccb840`:
  `if (region < 3) { if (region != 0) { dmg /= 2; if (dmg < 1) dmg = 1; } hp -= dmg; }`.
- Уверенность: высокая.
- Сейчас в порте: голова ×2, шея ×0 («гасит»), остальное ×1 (стр. 661–670).
- Что поменять: по регионам; шея наносит полный урон.

## 10. Шен: движение, стрельба, цвет

- Правило. Скорость = ввод × `m_flMaxSpeed` (420) сразу, без разгона (`m_flAccel` нигде не читается); позиция
  зажата в [45, W − 45] × [45, H − 45]. Выстрел: если перезаряд > 0 — уменьшить и не стрелять, иначе выстрелить

  `m_flAttackLaunchDistance`. Смена цвета: блок `m_nModeSwapTicks` (15) и перезаряд выстрела =
  `m_nModeSwapExtraAttackCooldown + перезаряд нового цвета` = 21 (присваивание, не max).
  Есть второй режим выстрела (флаг ввода `+0xb`): одна пуля, радиус ×1,5, урон 2.
- Доказательство: `FUN_182cf9210`: `if (0 < cd) { cd--; } else if (fire) { cd = def->fireCooldown; ... }`;
  `clamp(pos, 45, W-45)` (`0x42340000`).
- Уверенность: высокая (кроме привязки флага `+0xb` — см. ниже).
- Сейчас в порте: разгон 130/тик, рамка 40, период 6 тиков, `cooldown = max(cooldown, 15)` (стр. 221, 565–589).
- Что поменять: по правилу.

## 11. Смерть и возрождение Шен

- Правило. Жизни = `m_nLives` (5) + бонус первой игры; при попадании `жизни −= 1`, **конец игры, если жизней < 1**
  (5 попаданий без бонуса, а не 6). Состояния: dying → её отбрасывает (`vx = −300 − 500t`, `vy = 100 + 200t`,
  без рамки), переход в dead, когда прошло > 1 с и x < −50; dead: ставится в (0,2·W, 0,5·H) = (248,8; 350), через
  0,5 с (если жизни есть и игра не кончилась) → respawning: **3 с неуязвимости**, можно двигаться, стрелять,
  поглощать; вражеская пуля, коснувшаяся сердца, просто гаснет; столкновения с врагами не наносят вреда.
  **Пули при смерти и возрождении не очищаются.** Особая атака, начатая до смерти, достреливает.
- Доказательство: `FUN_182ccbb00` (`lives--; if (lives < 1) gameOver`; в respawning `return type < 2`),
  `FUN_182cfffd0`:
  ```c
  if (st == 1 && now - t0 > 1.0 && x < -50.0) set(2);
  if (st == 2 && lives >= 1 && now - t0 > 0.5) { set(3); if (combo>0 || chain>0) combo = chain = 0; }
  if (st == 3 && now - t0 > 3.0) set(0);
  ```
- Уверенность: высокая (время dying зависит от x: с x = 200 ≈ 1,0 с, у правого края ≈ 1,75 с).
- Сейчас в порте: `RESPAWN_TIME 1.25`, `INVULNERABLE 2.5`, `PLAYER_START [200, 350]`, гасит пули в радиусе 220,
  `killPlayer` даёт 6 попаданий, сбрасывает очередь особой атаки (стр. 189, 373–380, 598–605).
- Что поменять: по правилу (жизни включают текущую; HUD «Доп. жизни», видимо, = жизни − 1 — сверить с
  разметкой).

## 12. Поглощение и особая атака

- Правило. Пуля цвета Шен, задевшая щит (свиптест движущихся кругов), поглощается, +1 до
  `m_nMaxBulletAbsorption` (48), в состояниях alive/respawning. Старт (кнопка, поглощено ≥ 6, состояние не
  проверяется): `n = поглощено div 6`, поглощено `−= 6n` (остаток сохраняется); цели — враги по расстоянию
  (у врагов левее Шен расстояние ×1,1), цель k = `sorted[k mod числоВрагов]`. Выстрел k — раз в
  `m_nTicksPerSpecialAttack + 1` = 2 тика: угол `((k div 2)·0,05 + 0,4)·π`, у чётных k y зеркалится (веер
  вверх/вниз, ±72° и шире), радиус 15, тип = обычный выстрел текущего цвета (×2 по чужому цвету), урон
  `m_nSpecialAttackDamage` 8. Самонаведение каждый тик: `maxTurn = 0,019·t + (t > 0,015k ? min(1, 2t)·0,69 /
  max(1, √k) : 0)` рад/тик; скорость `min(600, 600/(k+1) + 500t) + (m_flSpecialAttackSpeed − 600) − 300·поворот`.
  Снаряд бьёт только свою цель (сквозь прочих), попадание — когда расстояние < радиуса цели (у босса — голова,
  R 50). Цель умерла → следующая живая из списка; нет целей → летит прямо, радиус ×0,9 до 3.
  Убийство врага **своего** цвета (цвет Шен = цвет врага) — враг выпускает ответный залп в Шен:
  `clamp(maxHP div 2, 3, 6)` пуль, PlayerSpreadRandom, 340 + 5i ед/с, R 7, ширина 0,02, все сразу, цвета врага —
  их можно поглотить.
- Доказательство: `FUN_182cfbf00`, `FUN_182d00cc0` (`fVar7 = ((k/2)*0.05 + 0.4)*π; if ((k&1)==0) dir.y = -dir.y;
  radius = 15.0`), `FUN_182cfefc0`, `FUN_182cc1350` (`if (game->color == enemy->red) { info.count =
  clamp(maxHp/2,3,6); info.speed = 340; info.radius = 7; info.width = 0.02; info.speedPer = 5; }`).
- Уверенность: высокая (знак поворота в формуле скорости — как в коде, без abs).
- Сейчас в порте: `special`/`steerShot` — по снаряду за тик, свой разлёт, поворот 2→9 рад/с, бьёт первого
  встречного; ответного залпа нет.
- Что поменять: по правилу; добавить ответный залп при убийстве своим цветом.

# Grid Studio: объединение инструментов в одном редакторе

## Что изменилось

Три отдельных инструмента для сеток Dota 2 объединены в единый сайт на React и Vite. Герои, рисование символами и конвертация изображений теперь работают с одним холстом и общим документом. Добавлены общая история отмены и повтора, автосохранение, слои и загрузка нескольких сеток из одного Dota JSON.

Редактор включает поиск героев по имени и атрибуту, игровые портреты, инструменты рисования и выделения, живой предпросмотр, контроль границ холста и экспорт в формате Dota v3. Для продолжения работы можно сохранить проект Grid Studio с сетками, слоями и черновиками. Старые автономные HTML-инструменты и пресеты остаются в репозитории.

## Документация и публикация

- README содержит установку, пошаговый рабочий процесс, форматы файлов, инструкции импорта в игру и горячие клавиши.
- В `docs/` описаны архитектура, проверки качества и возможности предыдущих инструментов.
- GitHub Actions проверяет исходники, запускает тесты и собирает сайт.
- Workflow GitHub Pages собирает `dist/` и публикует студию и автономные инструменты из `tools/`.

## Проверка перед выпуском

В проекте есть автоматические тесты и чек-лист браузерных проверок в [`qa.md`](qa.md). После слияния проверь статус обоих workflows и открой опубликованную студию и ссылки на автономные инструменты. Импортируй экспортированный JSON в актуальный клиент Dota 2, чтобы проверить отображение сетки в игре.

Исходники приложения лицензированы по MIT. В репозитории также есть изображения и шрифты Valve и другие сторонние ресурсы с отдельными условиями; их атрибуция приведена в [`assets/ATTRIBUTION.md`](../assets/ATTRIBUTION.md). Эти ресурсы не становятся частью MIT-лицензии приложения.

# Папка Steam в инструкции экспорта

В «Экспортировать» → «Файлом вручную» (шаги под выбором способа) есть поле «Ссылка на Steam или код друга» и кнопка «Найти папку». Поддерживаются код друга, SteamID64, ссылки `/profiles/SteamID64` и `/id/alias`, в том числе без схемы. Числовые варианты вычисляются в браузере через BigInt; ID 0, групповые ID, чужие домены и неподходящие ссылки отклоняются.

После определения кода показываем `C:\Program Files (x86)\Steam\userdata\ACCOUNT_ID\570\remote\cfg` с кнопкой копирования. В раскрывающемся поле можно изменить папку Steam, например на `D:\Steam`. Сайт не определяет диск пользователя по профилю. Путь с неподставленным ID или неверной папкой нельзя скопировать кнопкой. Изменение ввода сбрасывает прежний результат и отменяет запрос, закрытие окна тоже отменяет запрос. Последний ввод хранится только в памяти страницы, отдельно от проекта.

Модули:

- `scripts/steam-profile.mjs`: общая валидация, точное преобразование SteamID64 и сборка пути.
- `scripts/steam-folder.mjs`: форма в существующем окне экспорта; подключается из `scripts/app.mjs`, освобождается при закрытии, замене окна и dispose редактора.
- `server/steam-profile.mjs`: разрешение коротких ссылок, используется `GET /api/catalog/steam/resolve?profile=...`. Вход не требуется. Vite и production используют имеющийся API-прокси.

С необязательным **серверным** `STEAM_WEB_API_KEY` используется [ResolveVanityURL](https://partner.steamgames.com/doc/webapi/ISteamUser#ResolveVanityURL). Без ключа или при сбое API — [Steam Community XML](https://partner.steamgames.com/documentation/community_data?l=english): `https://steamcommunity.com/id/ALIAS/?xml=1`. XML официально устарел, поэтому ошибки объясняют пользователю возможность ввести код друга. Ключ не отдаётся в публичный config и никогда не имеет префикс VITE_.

Сервер строит URL только для фиксированных Steam-хостов и не следует перенаправлениям. Таймаут каждой попытки 4,5 с, ответ до 256 КиБ, кэш положительных результатов на 15 минут (до 512 записей), до 16 одновременных запросов, одинаковые запросы объединяются. API ограничивает 20 запросов/IP/минуту и 300 суммарно/минуту. Ошибки стороннего сервиса не раскрываются как есть и не содержат ключ. SteamID64 принимается строкой, чтобы не терять точность.

Проверено 28.09.2026: реальный XML и интерфейс для `https://steamcommunity.com/id/7771/` вернули SteamID64 `76561199128668433`, AccountID `1168402705`. Проверены копирование пути, другой диск, неверная ссылка и прямой код. Восемь тестов `tests/steam-profile.test.cjs` покрывают преобразования, валидацию адресов, XML/API, кэш, ошибки и HTTP-лимиты. Сценарий с настоящим API-ключом проверен подставным ответом; ключ для живой проверки не требовался. Production build и выкладка не выполнялись.

## Установка командой PowerShell (02.10.2026)

Пользователь попросил ставить сетку скриптом в нужную папку, беря аккаунт, который сейчас вошёл в Steam, — командой, которую вставляют в PowerShell (сначала был архив с `.bat`; заменён в тот же день: «чтобы юзер команду в повершелл вставил и все»). В окне «Экспортировать» (`openExport` в `scripts/app.mjs`) два способа карточками одного размера; окно одной ширины для обоих. По умолчанию всегда «Файлом вручную» (видео и шаги с полем Steam); «Командой PowerShell» — только на Windows. В мастерской «Как установить» устроено так же: карточки «Файлом вручную» / «Командой PowerShell», по умолчанию файл, окно 680 px; команда (`gridInstallCommand` в `src/catalog/api.js`, через pick-safe, как обычная загрузка) делается только после выбора.

Как работает:

- «Скопировать команду» отправляет тот же `hero_grid_config.json`, что скачался бы, в `POST /api/catalog/install` (`server/grid-installs.mjs`, таблица `installs` в базе мастерской): проверяется форма файла Dota (1–100 сеток с `categories`) и размер (до 8,9 МБ, nginx пропускает 9 МБ); хранится 7 дней, та же сетка на том же языке получает тот же адрес (HMAC содержимого), повтор только продлевает срок. Больше ничего об отправителе не хранится. Лимит — 60 команд за 10 минут с одного IP (команда готовится сразу при выборе способа и при открытии «Как установить» в мастерской, кнопка только копирует).
- Команда — `installCommand(address)` из `scripts/installer.mjs`: `[Net.ServicePointManager]::SecurityProtocol = 'Tls12'; irm <адрес> | iex` (Windows PowerShell 5.1 может по умолчанию не включать TLS 1.2, сайт работает на 1.2/1.3).
- `GET /api/catalog/install/<id>` отдаёт `gridScript` с `text/plain; charset=utf-8` (без charset PowerShell 5.1 читает страницу как ISO-8859-1). Скрипт в своей области `& { … }`, чтобы не менять настройки PowerShell пользователя. С 03.10.2026 (пользователь: «и сетку так же») сетки в скрипте нет: он скачивает `hero_grid_config.json` байтами с `GET /api/catalog/install/file/grid-<id>` (компактный JSON с заметкой сайта, UTF-8 без BOM, пока жив адрес; иначе 404) во временную папку, сверяет размер и SHA-256 из скрипта (общий `DOWNLOAD` с фоном и шрифтом) и копирует файл как есть, временный удаляет. Кодировка, в которой PowerShell прочитал страницу, на сетку больше не влияет (раньше JSON лежал в here-string `@'…'@`, и неверная кодировка ломала буквы). Ошибка скачивания — «нет интернета», 404 — «команда устарела», не сошлась сумма — «вставь команду ещё раз». Просроченный адрес отвечает строкой «команда устарела», а не ошибкой.
- Steam: `SteamPath`/`InstallPath` из реестра (HKCU, HKLM, WOW6432Node), иначе `Program Files (x86)\Steam`; нужна папка `userdata`.
- Аккаунт: `HKCU\Software\Valve\Steam\ActiveProcess\ActiveUser` (DWORD, читается как Int32 — отрицательный переводится в беззнаковый); если 0 (Steam закрыт или никто не вошёл) — `config\loginusers.vdf` с `MostRecent "1"` (SteamID64 − 76561197960265728); иначе единственная папка в `userdata`; иначе список с именами и выбор номером. Скрипт печатает имя и код друга.
- Ждёт закрытия Dota (`dota2`), пишет `userdata\<id>\570\remote\cfg\hero_grid_config.json` (UTF-8 без BOM); прежний файл копирует в `userdata\<id>\570\gridstudio-backup\hero_grid_config-<дата>.json` — вне `remote`, который синхронизирует Steam Cloud. В конце печатает команду возврата.
- Возврат: `…/install/restore` (`restore-en` по-английски) — `gridRestoreScript` кладёт на место самую новую копию и удаляет её: следующий запуск вернёт копию ещё раньше. Ничего не скачивается и не запускается, кроме самого скрипта.

Проверено тестами (`tests/customize.test.cjs`: скрипт, адрес, повтор, срок) и в браузере; на Windows команду нужно проверить на живом Steam.

## Подпись в файле (с 02.10.2026)

Каждый `hero_grid_config.json`, который отдаёт сайт, начинается с поля `"_comment": "Сетка создана и скачана с gridstudio.me"` (на английском сайте — по-английски): скачивание из редактора, в том числе «Оптимизированный JSON», из мастерской (`downloadGrid`, `/works/:id/download`) и файл, который пишет команда PowerShell (`ensureGridNote` в `server/grid-installs.mjs` добавит подпись, если страница её не прислала). Комментариев в JSON нет, поэтому это отдельное поле, первым: `scripts/grid-note.mjs`. Dota читает только `version` и `configs` и при своём сохранении поле выбрасывает; импорт сайта (`importDota`) его тоже не замечает. В игре пока не проверено.

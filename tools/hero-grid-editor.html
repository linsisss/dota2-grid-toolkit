Каждая строка в поле «Символы» = отдельный символ сверху вниз.

ASCII — символы

Показывает уникальные символы из ASCII-категорий. В поле справа можно задать замену: например ⣟ → ....

Масштаб выделенного

Масштабирует рамки выделенных категорий относительно общего центра. Символы внутри не растягиваются — меняется только расположение и размер плиток.

Замена символов выделенного

Меняет текст/символ во всех выделенных текстовых категориях. Введи новый символ (или строку) и нажми «Заменить».
Размер рамки подстроится под новую строку автоматически. Ширина пересчитывается по формуле len × fontSize × 0.6.

# Съёмка интерфейса Dota для GridStudio

Скрипт `gs-hud-capture.ps1` проводит всю съёмку сам: ставит тестовые пакеты, сам снимает экран Dota и в конце
возвращает твой `pak03_dir.vpk`. Подробная инструкция — в окне скрипта, по шагам.

С 17.10.2026 Steam не нужен: скрипт снимает окно Dota сам (общий код с съёмкой меню —
`tools/capture-common/gs-capture-common.ps1`). F12 ты нажимаешь только чтобы сказать «готов» (старт и после
переключения «Режима цветовой слепоты»), дальше скрипт снимает сам. Dota должна быть в режиме «Окно без рамок»,
1920×1080: полноэкранную скрипт на время съёмки переключит сам (`video.txt`, в конце вернёт).
Старый путь через скриншоты Steam — параметр `-Steam`.

## Обычный способ

1. Steam ничего настраивать не нужно.
2. Закрой Dota. Открой PowerShell и вставь:

   ```
   iex ([Text.Encoding]::UTF8.GetString((New-Object Net.WebClient).DownloadData('https://dev.gridstudio.me/hud-capture.ps1')).TrimStart([char]0xFEFF))
   ```

3. Делай, что пишет скрипт. Всего 7 запусков Dota подряд (C1, пять S-…, C2), около 30 минут.
   Сигналы: двойной — переключи «Режим цветовой слепоты», курсор в точку Б, F12;
   тройной — пакет готов, закрой Dota; длинный низкий — загляни в окно PowerShell.
4. В конце на рабочем столе будет `gs-hud-capture.zip` (снимки `C1_0001.png`…, `session.json`).
   Загрузи его на 0807.st как файл и пришли ссылку (не через Telegram).

Если Dota упала с ошибкой или окно закрылось — скрипт сразу возвращает твой `pak03_dir.vpk`. Если окно
PowerShell закрылось или компьютер выключился — запусти ту же команду ещё раз: она сначала вернёт твой
`pak03_dir.vpk`, потом предложит продолжить съёмку.

## Если скрипт не запускается — вручную

Пакеты: `https://dev.gridstudio.me/hud-capture/<пакет>/pak03_dir.vpk` — по очереди C1, S-70-70, S-80-80,
S-90-90, S-85-110, S-95-120, C2 (F-bg — только если попросили). Папка: `Steam\steamapps\common\dota 2 beta\game\dota_russian`.

1. Закрой Dota. Переименуй свой `pak03_dir.vpk` в `pak03_dir.vpk.bak` (в первый раз, если он есть).
2. Положи туда `pak03_dir.vpk` пакета.
3. Dota → Герои → Keeper of the Light → «ОПРОБОВАТЬ». Ничего не покупай, способности не изучай.
4. F9 (часы вверху должны встать). В чат: Enter → го рошан → Enter; Shift+Enter → gg wp → Enter; Enter → нужна мана → Enter.
5. Курсор в точку А: у правого края (3–4 см), на четверть высоты сверху, над землёй. Мышь больше не трогай.
   Жми F12 примерно раз в секунду: C1 — 2 минуты, потом переключи «Режим цветовой слепоты», курсор в точку Б
   (у правого края, середина высоты) и ещё 2 минуты; S-… и C2 — по минуте. Закрой Dota, следующий пакет.
6. Если Dota падает с ошибкой — сразу верни свой pak03 и пришли текст ошибки.
7. В конце удали тестовый `pak03_dir.vpk` и верни свой (`pak03_dir.vpk.bak` → `pak03_dir.vpk`).
8. Упакуй все PNG из `C:\GSShots`, сделанные за эту сессию, в один zip и загрузи на 0807.st.

## Для разработчика

- Проверка без Windows и без Dota (фальшивая папка Dota, синтетические кадры, полный прогон сессии):
  `pwsh -File tools/hud-capture/gs-hud-capture.ps1 -SelfTest [-KitDir <packs>] [-ProbeDir <кадры>] [-OutDir <tmp>]`.
- Параметры для отладки на Windows: `-Base` (сайт или локальная папка с `manifest.json`), `-DotaDir`, `-OutDir`; `-Steam` (+ `-ShotsDir`) — старый путь через скриншоты Steam.
- Общий блок съёмки экрана правится в `tools/capture-common/gs-capture-common.ps1`, в оба скрипта его копирует `node scripts/sync-capture-common.mjs` (тест `tests/capture-common.test.cjs` следит).
- Геометрия проб, метки и правила остановки берутся из `manifest.json` → `plan.snapshot` (scripts/hud-capture/plan.mjs).
- Файл хранится в UTF-8 с BOM (Windows PowerShell 5.1); C# внутри — не новее C# 5.

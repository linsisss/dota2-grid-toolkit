# Съёмка главного меню Dota для GridStudio

Скрипт `gs-menu-capture.ps1` проводит съёмку сам:
- ставит тестовые пакеты вместо твоего `pak02_dir.vpk`;
- на время убирает `pak03`/`pak04`, чтобы Dota показала чистое меню Valve;
- переключает Dota в «Окно без рамок», если она полноэкранная;
- сам снимает окно Dota — Steam и F12 не нужны;
- в конце всё возвращает.

## Как снимать

1. **Запуск.** Закрой Dota. Открой PowerShell и вставь:

   ```
   iex ([Text.Encoding]::UTF8.GetString((New-Object Net.WebClient).DownloadData('https://dev.gridstudio.me/menu-capture.ps1')).TrimStart([char]0xFEFF))
   ```

2. **Два запуска Dota:** M1 — около 5 минут, V1 — около полутора минут. В каждом:
   - дождись главного меню и закрой всплывающие окна;
   - открой главную (логотип Dota слева вверху);
   - курсор поставь в пустую середину экрана, между друзьями и новостями, и не двигай мышь.

   Скрипт сам увидит меню и начнёт снимать. Фон будет мигать чёрным, белым и серым, а части меню — пропадать:
   так и задумано. Dota не сворачивай.
   Сигналы:
   - короткий — скрипт начал снимать;
   - тройной — пакет готов, закрой Dota;
   - длинный низкий — загляни в окно PowerShell.
3. **Если скрипт пишет про чёрный экран или размер окна:** Настройки Dota → Видео → Режим отображения →
   «Окно без рамок», разрешение 1920×1080.
4. **Архив.** В конце на рабочем столе будет `gs-menu-capture.zip` (`M1_0001.png`…, `V1_0001.png`…,
   `session.json`). Загрузи его на 0807.st как файл и пришли ссылку (не через Telegram).

Если Dota упала с ошибкой или окно закрылось, скрипт сразу возвращает твои файлы и режим экрана. Если закрылось
окно PowerShell — запусти ту же команду ещё раз: она сначала всё вернёт, потом предложит продолжить.

Старый путь через скриншоты Steam (F12, внешняя несжатая копия в `C:\GSShots`) — параметр `-Steam`.

## Для разработчика

- **План** — `scripts/menu-capture/plan.mjs`:
  - 21 часть меню;
  - M1: 23 состояния по 6 с (защита 0,75 / ядро 4,5 / защита 0,75), цикл 138 с;
  - V1: 4 состояния, цикл 24 с, прятанье кнопок и карточки как в продакшене;
  - фон K/W/G по 1,5 с;
  - код-метка: две строки по 4 квадрата, каналы только 0/255.
- **Сборка:** `node scripts/make-menu-capture.mjs <out> [--offline] [--valve-css <panorama/styles>]`.
  - Проверки при сборке: ASCII, нет обработчиков в новых разметках, в `@keyframes` только свойства из
    `VALVE_KEYFRAME_PROPS` (с `--valve-css` ещё и по всему корпусу Valve), одна анимация на панель,
    селекторы — по разметке Valve, VPK читается обратно.
- **Выкладка на dev:**
  - `dev/current/menu-capture/{M1,V1}/pak02_dir.vpk`, `manifest.json`, `plan.json`;
  - `dev/current/menu-capture.ps1` — этот файл как есть, с BOM.
- **Решатель, этап 1:** `node scripts/menu-capture-solve.mjs <zip или папка> [--report <папка>]`. Он считает:
  - фон и код каждого кадра;
  - покрытие;
  - рамки частей;
  - движение;
  - часы панелей;
  - сдвиги кнопок в V1.
- **Съёмка экрана** — общий блок `tools/capture-common/gs-capture-common.ps1` (тот же в `gs-hud-capture.ps1`):
  - GDI BitBlt клиентской области окна dota2.exe, когда оно на переднем плане;
  - процесс DPI-aware, курсора в кадре нет, байты как есть, PNG без потерь;
  - проверки: размер окна 1920×1080, чёрные или застывшие кадры (полноэкранный режим);
  - старт — меню с метками и курсор неподвижен 2 с в середине.

  Блок правится в источнике, в скрипты его копирует `node scripts/sync-capture-common.mjs`.
- **Самопроверка без Windows и Dota:** `pwsh -File tools/menu-capture/gs-menu-capture.ps1 -SelfTest -KitDir <out>`.
  Её же запускает `GS_PWSH=<pwsh> node --test tests/menu-capture-watcher.test.cjs`.
- Файл хранится в UTF-8 с BOM (Windows PowerShell 5.1). C# внутри — не новее C# 5. `GsWinV1` побайтно как в
  `gs-hud-capture.ps1`.
